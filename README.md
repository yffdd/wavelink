# WaveLink

WaveLink 是一款面向串口调试、网络数据收发和多通道波形分析的 Windows 上位机。支持文本与波形收发、数字滤波、频谱与信号分析、命令交互、状态监视、CSV / WLR 录制和离线导入。没有设备时，可使用内置 Demo 数据熟悉操作。

**当前版本为 v0.14（2026 年 11 月）。** 本版新增示波器测量和绘图背景设置，修复读数越界及独立视图通道操作异常。离线导入保留完整数据，大文件支持按需浏览。主视图右键菜单新增导入和导出入口，清空波形前需确认，迁移配置时保留本机缓存路径。命令交互和状态监视面板新增自定义分行布局，支持拖动排序，并可随面板保存和迁移。历史版本可在帮助中心的【更新日志】查看。

## 1. 安装与快速开始

### 1.1 安装与启动

- 运行 Setup 安装程序，按向导安装并启动 WaveLink。
- 从源码构建需要 Qt、MinGW 和 CMake。工程入口为 [CMakeLists.txt](WaveLink/CMakeLists.txt)，工具配置见 [打包部署指南](deploy/readme.md)。

点击主窗口右上角的【?】可打开帮助中心，查看使用指南、协议说明和程序诊断信息。

### 1.2 连接设备

1. 在左侧【参数设置】中选择【数据接口】。下拉顺序为串口、TCP 客户端、TCP 服务端、UDP 用户数据报、BLE 低功耗蓝牙、Demo 数据。悬停接口标签、选项和设备连接区控件可查看用途和操作提示。
2. 根据设备实际发送的格式选择数据协议，参见下表。协议旁的【?】提供格式和示例。
3. 按接口填写参数。串口需核对端口、波特率、数据位、校验位和停止位。TCP / UDP 需设置地址和端口。填写后打开或连接设备。Demo 数据可配置波形参数后点击【启动 Demo】。
4. 在底部【数据收发】查看接收内容和发送数据。使用数值协议时，在主视图及右侧【数据通道】查看波形。

| 设备数据格式 | 协议选择 |
| --- | --- |
| 普通文本或字节调试 | Raw（文本 / HEX） |
| 逗号分隔的数值行 | FireWater（CSV 文本） |
| 二进制浮点数 | JustFloat，按设备设置大小端 |
| 多行键值数据 | 自定义协议中的多通道键值协议。CBF / IR / RED 设备可使用模板，键 0、1、2 分别对应 CBF、IR（LED1）、RED（LED2） |

## 2. 数据接口

### 2.1 串口

#### 2.1.1 DTR 与 RTS

串口参数末尾提供 **DTR / RTS** 复选框，默认关闭并自动保存。连接前设置供下次打开使用，连接后切换在后台应用。DTR / RTS 与硬件流控分开设置，按设备需要启用。部分开发板会因控制信号变化复位或进入下载模式，请按设备说明使用。驱动不支持时会提示，未确认的信号在当前连接中显示为半选并禁用，不会仅因此中断接收和录制。

Windows 下，在串口句柄打开后、报告连接成功前合并应用 DTR/RTS 并释放 Break。关闭前再次核对用户请求的控制状态，不恢复打开前的旧串口设置。相同且已确认的状态不重复切换。驱动未确认时不通过逐个切换控制线来盲目重试。

ESP32 等使用控制线自动复位的设备，普通调试应选择无流控并按需释放 DTR/RTS。取消勾选是请求释放信号，不代表能阻止驱动在打开/释放句柄瞬间产生电平变化，也不保证所有板子完全不复位，仍需实机核对。

#### 2.1.2 硬件流控

在【停止位】下方的【流控】中选择【无流控（默认）】或【硬件流控（RTS/CTS）】。设置自动保存，连接期间不可修改。使用硬件流控需要转换器、设备和接线同时支持。启用后，驱动接管 RTS。切回无流控后恢复手动 RTS 设置。

- CTS 未就绪时显示等待状态和待发送大小，接收及录制继续。发送队列最多容纳 256 KB 或 1024 条请求，达到上限后拒绝新命令并停止命令循环。
- 文件发送按写入完成情况更新进度。读取到文件末尾后仍会等待写入完成，发送过程禁止混入其他命令。
- 取消待发送或停止文件发送时，丢弃软件队列中的数据，后续由用户手动发送。仅在软件队列等待时可以保留连接。若驱动中已有未完成的写入，则断开串口、停止录制，并弹窗说明。

已提交到驱动或硬件的少量字节仍可能到达，无法撤回。串口写入完成也无法确认设备已执行业务操作。

#### 2.1.3 Break

【Break】控制特殊设备的发送线。点击【发送】可按设定时长保持并自动释放。勾选【保持】可持续保持，取消勾选或点击【释放】结束。每次启动和重新连接均默认释放，只保存时长。

Break 期间，普通发送和文件发送不可用，命令循环停止。驱动不支持时会提示并禁用该功能，无法确认释放时会关闭串口。普通调试通常无需启用。Break 与发送字节 `0x00` 是两种操作，时序也不适用于精确定时的 LIN / DMX 发送。

### 2.2 TCP 网络连接

#### 2.2.1 TCP 客户端

| 参数 | 设置方式 |
| --- | --- |
| 远端 IP 和端口 | 填写设备的实际地址或主机名，端口为 1–65535。`0.0.0.0` 仅用于本机地址设置。 |
| 本机 IP | 默认 `0.0.0.0`，由系统选择出口地址。固定源地址时填写本机已有的 IP。 |
| 本机端口 | 默认 `0`，由系统分配。固定源端口时填写未被占用的端口。 |

连接成功后显示实际本机 IP 和端口，自动分配的端口不会写回设置。使用主机名并指定非零本机端口时，填 `0.0.0.0` 选择 IPv4，填 `::` 选择 IPv6。

#### 2.2.2 TCP 服务端

监听端口默认为 `4970`。监听 IP 可从下拉框选择，也可手动输入。

| 监听地址 | 接收范围 |
| --- | --- |
| `0.0.0.0`（默认） | 所有本机 IPv4 地址 |
| `127.0.0.1` | 仅接受本机连接 |
| 指定网卡 IP | 仅在该地址监听 |
| `::`（手动输入） | 所有本机 IPv6 地址 |

开启监听后，需等待客户端接入才能发送。监听全部网卡时，局域网其他设备可能接入。请按需选择网卡，并核对 Windows 防火墙权限。

#### 2.2.3 TCP 参数保存与排查

TCP 参数自动保存，并随【设置】中的全局配置导入和导出。连接或监听期间不可修改。导入后更新参数，连接需手动建立。

IP 无效、不属于本机、端口被占用或远端连接失败时，软件会提示原因，且不会改用其他地址或随机端口。设备 TCP 采用直连，系统 HTTP / SOCKS 代理配置照常保留。

### 2.3 UDP 数据收发

#### 2.3.1 绑定与远端设置

在【数据接口】中选择【UDP 用户数据报】。UDP 使用本机监听和可选的远端地址，收发无需划分客户端与服务端。

- 本机 IP 默认为 `0.0.0.0`，监听所有本机 IPv4 地址。也可选择或输入指定地址，IPv6 可手动输入 `::` 或具体地址。本机和远端需使用相同的地址类型。
- 本机端口默认为 `4970`，设为 `0` 时由系统分配。打开后显示实际地址和端口，自动分配的端口不会写回设置。设备应向电脑实际网卡 IP 和监听端口发送。
- 仅接收时，远端 IP 留空、端口设为 `0`。发送时填写远端单播 IP 和 1–65535 范围内的端口。勾选【仅接收远端数据】后，已配置远端时只接受源 IP 和源端口均匹配的数据。未配置远端时接受所有来源。

建议一个监听端口对应一台波形设备。UDP 支持单播 IP，暂未提供主机名、广播和组播。参数独立自动保存，可随全局配置迁移。重启或导入后需手动打开监听。

#### 2.3.2 接收、解析与发送

点击【打开 UDP】后显示“UDP 监听中”。远端是否在线需另行核对。支持 Raw 文本 / HEX、命令面板、定时发送、内置及自定义协议绘图和 CSV / WLR 录制。

- 每个数据报独立解析，一包可含一帧或多帧。文本需带结束符，键值协议需在同一包内包含完整通道组。残缺帧不会跨包拼接。JustFloat 仍会验证同源连续帧的通道数。
- 单次发送对应一个数据报，最多 65507 字节。软件不会自动拆包，建议控制包长以避免网络分片。UDP 暂未提供文件发送。发送计数统计已交给本机系统的数据。
- UDP 可能丢包、乱序或重复。录制保存实际接收并成功解析的数据。重要采集可由设备提供连续序号与校验，或改用 TCP。
- 绑定或收发失败时会提示错误并停止相关操作，端口不会自动切换，数据不会自动重发。请核对 Windows 防火墙的 UDP 入站权限。

### 2.4 BLE 低功耗蓝牙

#### 2.4.1 扫描与收发配置

1. 在【数据接口】选择【BLE 低功耗蓝牙】，点击【扫描…】，选中设备后点击【连接 BLE 设备】。需要配对时，先在 Windows 设置中完成。
2. 发现服务后，在【BLE 快速收发配置】选择接收或发送特征。收发方向以电脑为准。接收选“电脑接收（设备 → PC）”的 Notify / Indicate 特征，发送选“电脑发送（PC → 设备）”的可写特征。可只配置一个方向。
3. 点击【应用并开始调试】。订阅成功后可使用文本 / HEX 收发和命令交互。

【使用候选通道】可预选收发特征，【仅接收候选通道】可先观察通知。候选基于特征属性和服务结构，需确认是否用于透传，软件不会发送探测命令。已知 Nordic 固件升级服务不参与推荐，手动选择时会提示。写入模式按特征自动适配，优先使用有响应写入。缺少选择或模式冲突会提示原因。

完整服务树、模板、写入模式、读取特征及分包控制位于默认收起的【高级配置】。配置成功后按设备保存。下次连接重新发现服务并核对结构、UUID 和属性。核对一致且发送参数无需再次确认时直接应用。旧配置、修改后的下次配置、重复 UUID、结构变化和需风险确认的高级参数仍须核对。连接不会自动发送业务命令。

【收发配置…】可查看当前确认的配置，以及编辑供下次连接使用的 UUID 和写入模式。保存不会在线替换当前收发通道。【保存并重新连接…】会先确认，再重新发现服务并核对通道。录制、文件发送或连接操作进行中只允许查看。

#### 2.4.2 分包和发送间隔

展开【高级发送控制】，可设置分包大小（1–512 字节）和每包完成后的最小间隔（0–1000 ms），默认为 20 字节、10 ms。

界面分别显示设置值与实际生效值。实际分包受 Windows 协商的 MTU 减去 3 字节 和后端 512 字节上限限制。能力未知时最多 20 字节。模块缓冲容量需按实际设备核对。增大分包或缩短间隔需要明确确认。导入模板不会自动授权提速。0 ms 仍逐包等待 GATT，不会并发发送。

发送空闲时可【仅应用发送参数到当前连接】，确认成功后自动保存到该设备，不改变当前或已保存的下次连接 UUID。

能力增大不会自动提速。能力降低到不适合当前分包时，会停止待发数据并提供可复制提示，接收和录制继续运行。已提交的一包仍可能到达设备，不自动重发。重新应用合适参数后，由用户手动开始新发送。未经真实模块测试，不能保证更快参数不会导致外设丢包。

#### 2.4.3 配置模板和连接诊断

可以保存、导入和导出自定义 JSON 模板。模板不包含设备名称、蓝牙地址、文件路径和临时句柄。导入需要确认，同名模板覆盖也需确认。内置 Nordic UART 模板只是结构匹配候选，只有唯一 UUID 匹配才预选，仍需核对属性和透传用途。不会按设备名称猜测。HC-08 / E104-BT52 尚未实测，不附带猜测的专用 UUID 模板。

【连接诊断…】每秒更新可复制的状态、阶段耗时、通知与字节数、解析/录制计数及仅显示队列丢帧数。设备身份和错误路径默认隐藏，可主动勾选完整信息。未知适配器或 MTU 能力会标为未知。写入已接纳不等于已刷写到磁盘，Tx 也不等于设备业务确认。

#### 2.4.4 接收数据与录制

BLE 默认使用 Raw 文本/HEX 调试。外设发送数值时，可选择 FireWater、JustFloat（核对大小端）或匹配的自定义协议（包括多通道键值、CBF/IR/RED 模板），使用波形、滤波、频谱与信号分析，以及 CSV/WLR 录制和离线导入。录制时保留 Windows 通知的原始接收时间，跨通知的数值帧使用组帧完成那次通知的时间，同一通知中的多帧可能共用时间戳。

CSV 的时间列为 `UnixTime(s;FS=...)`，以秒为单位保存主机接收时刻的 Unix 时间戳，FS 是采样率参考值。旧 `HostReceiveTime` 和 `Hint` 文件仍可导入。导入时可按现有“重建时间轴”机制查看批量发送的数据。

协议解析和录制在后台进行，录制先于绘图限流。接收积压或协议缓冲超过安全上限时会明确报错并停止连接，不能据此保证无线链路绝不丢包。Raw 模式和没有接收特征的连接不开放波形录制。录制期间不能切换协议。

#### 2.4.5 文件发送与 Windows 后端

BLE 文件发送在独立后台进程中打开和分段读取文件，使用有界缓冲和当前实际生效的分包/间隔。准备文件时显示等待状态，进度按 GATT 写入完成/提交计算，最后一包确认前不显示完成。

发送期间禁止混入手动命令或循环命令，也不能修改发送参数。取消/掉线会清空尚未提交的数据，已提交的一包无法撤回，等待其结算后才可再次发送，也不会在重连后自动重发。

源文件读取失败或超时会停止文件发送并提供可复制提示，不主动中断仍健康的 BLE 接收和录制。发送过程中请勿修改源文件。发送完成不等于外设业务层确认，非透传控制特征不要用自动分包发送。

经典蓝牙虚拟 COM 口继续使用串口接口。

Windows BLE 后端由同目录的 `WaveLinkBleHost.exe` 提供。安装包和多文件便携包会包含它。Enigma 打包的便携程序也需附带这个辅助文件。开发时先运行 `deploy/Build_BLE_Host.bat Debug`，重新配置并构建 Qt 工程后会自动复制到主程序旁边。

## 3. 自定义数据协议

### 3.1 创建与管理协议

1. 在【参数设置 → 数据协议】选择【自定义协议】。蓝色【⚙ 管理自定义协议】按钮随之显示。
2. 打开管理窗口，点击【新增协议】并选择协议类型。新草稿会出现在列表中并选中，列表名称随编辑更新。
3. 配置通道名称、单位、换算和校验，用样例验证后点击【保存协议】或按 `Ctrl+S`。放弃新草稿会移除列表项，放弃已有协议的修改会恢复到已保存版本。
4. 返回主界面并选择要使用的自定义协议。软件自动应用所选协议。缺少可用协议时，会提示新建或导入并阻止建立连接。

新建协议的默认名称如下。重名时自动追加 `_1`、`_2` 等后缀。

| 默认名称 | 默认结束符或帧尾 |
| --- | --- |
| 文本分隔协议 | `0D0A` |
| 二进制固定长度帧协议 | `0D0A` |
| 二进制长度字段帧协议 | `0D0A` |
| 二进制首尾分隔协议 | JustFloat 小端帧尾 `0000807F` |
| 多通道键值协议 | `0D0A` |

管理窗口采用三栏布局。左上是协议列表，左下是管理操作，中间是协议配置，右侧是样例测试。各栏可拖动调整宽度，内容可滚动查看。管理区提供新增、删除、导入、导出所选、导出全部及使用说明。使用说明按分类导航并适配主题，窗口可缩放，内容可选中复制。删除支持 `Ctrl` 或 `Shift` 多选，确认后统一处理。

协议列表右键可复制、重命名、排序，也可查看当前项的【协议说明】。副本紧跟原项，名称自动追加后缀，采集仍使用原选择。校验摘要、范围和长度修正见下方的帧规则说明。

### 3.2 字段、通道与数值范围

#### 3.2.1 文本字段与通道顺序

文本配置按固定前缀、固定后缀、分隔方式、分隔符、结束符排列，前缀与后缀可空。将鼠标悬停在配置项名称或表头可查看说明。结束符、二进制帧头/帧尾及固定字节条件只接受十六进制字符和分隔空白，小写自动转为大写。含非法字符的粘贴不改变原内容。每字节需两位，不填写 `0x`，保存时仍校验完整字节及帧规则。普通文本前缀、后缀和分隔符不受 HEX 限制。

【通道配置】文本协议自动读取全部数值列，表内只需配置需要自定义名称、单位或换算的列，列号从 0 开始。输出先按表格顺序排列已配置通道，再按原列顺序追加未配置列。后者默认命名为“ChN”（N 为原列号 + 1）、无单位、保留原始数值。通道表可留空。配置 2 路时输入 4 列仍读取 4 路，测试和实际接收一致。每帧最多输出 256 路。空列、无效格式、无穷大或通道数超限会拒绝整帧。

#### 3.2.2 二进制字段与换算

二进制协议仍按表内字段的数据区偏移、类型和大小端提取。换算值为“原始值 × 系数 + 换算偏移”。新增通道默认名称为“Ch1、Ch2……”，已有和导入的名称保留。大小端的“默认”表示继承协议设置。【固定字节条件】可筛选命令码或报文类型，例如要求完整帧偏移 2 为 `01`。全部条件匹配才接受，可留空，不代替校验。

通道表末尾的【备注】默认为空，可填写中英文、数字和符号（单行，最多 1024 个字符），随协议保存、复制以及独立协议/全局配置导入导出，不参与数值解析或换算。单位同样可自由填写。

数据偏移、文本列号及数组序号只接受非负整数。系数、换算偏移、最小/最大值只接受有限数值，支持负数、小数及科学计数法，小数点使用英文句点，不接受中文或其他非数字内容。最小/最大值可留空，系数和换算偏移不可留空。键值协议的【通道键】仍支持文本，不受偏移输入限制。

新建协议默认无校验，通道系数为 1、偏移为 0。已有协议和独立教学示例保留其校验与系数。二进制新增通道的偏移接在前一字段末尾，例如 `int16` 加 `float32` 后的偏移为 6。改变类型、删除或移动通道后，按字段顺序及实际宽度从 0 重算。

通道表完整向下展开，使用协议配置的整体滚动条查看。最大化时各配置行仍保持正常间距。

#### 3.2.3 通道命名与超限规则

通道名称留空时，保存协议自动补为 `Ch1、Ch2…`。文本未配置列使用 `ChN`（N 为原列号 + 1）。CSV、WLR 录制及波形导出保存对应名称，导入后通道列表、波形和分析选择恢复文件中的名称。已有名称不覆盖。CSV 支持中文名称及逗号/引号转义。旧 WLR 无名称元数据时使用默认 `ChN`。

通道最小值和最大值用于校验**换算后的数值**。允许边界值，留空表示无限制，绘图 Y 轴范围可单独设置。

- 【超限通道标记为 NaN，其他通道保留】排在第一项，是新建二进制及多通道键值协议的默认值。超限值在绘图、分析和当前波形导出中记为 NaN。原始数值录制保留真实读数，换算后数值录制保存 NaN，均不裁剪到边界。
- 【拒绝整帧】排在第二项，是新建文本分隔协议的默认值。已有协议保留原设置。
- 拒绝整帧、格式错误、无穷大（Inf）、换算溢出及帧结构或校验错误均不生成自定义协议录制帧。需要保留超范围读数时，使用 NaN 模式并录制原始数值，或放宽范围。

设备发送的 NaN 表示缺失采样点。文本数值协议支持大小写不同的 `NaN`，也接受 `+NaN` 和 `-NaN`。二进制数值协议按所配置的浮点类型和大小端识别 IEEE 754 NaN。NaN 保留该通道和时间点，波形显示断点，原始及换算录制均保存 NaN。同帧的其他通道继续按配置解析。Raw 直接显示接收到的字节或文本。

### 3.3 二进制帧规则

#### 3.3.1 数据区、长度和结构摘要

新建固定长度二进制协议默认开启【数据区与通道自动关联】。修改通道数量/类型更新固定数据区字节数。增大数据区时，每个未配置的完整 4 字节补为 float32 通道（ChN、系数 1、无单位），不足 4 字节标明为保留字节，不猜测数据类型。缩小会删掉无法完整容纳的通道，需先确认，取消则保留原配置。

固定总帧长、变长最小总帧长和末尾校验位置同步调整。选择设备长度字段的含义后，系统自动计算单位与修正值。最多 256 路，更多完整字段不能静默截断。

固定长度帧只有帧尾且没有数据校验时，解析器按配置总帧长检查帧尾位置。长度不符的片段会丢弃，再从完整帧尾恢复同步。若连接从半帧或杂字节开始，首段可能随同步过程丢弃。能够修改下位机格式时，可增加帧头和数据校验来区分错位、损坏与完整帧。

这类协议实时接收时，须连续通过 3 帧才确认同步，从第 3 帧开始绘图和录制。遇到坏帧、重连或 UDP 来源变化时重新确认。UDP 可累计同一来源的完整报文，截断报文会中断确认。协议管理窗口可用单帧样例核对格式。

已有/导入的特殊布局保持手动模式和原偏移。需要联动时主动勾选，也可关闭联动手动配置保留字节。

长度字段支持 1/2/4 字节无符号长度和帧长上下限。只需选择【数据区字节数】【整帧字节数】，动态数组还可选择【通道数量】。总帧长修正由系统根据总帧长、头尾、数据和校验配置计算，不再手动设置。固定字段模式的长度开销为最小总帧长减去固定数据区字节数。

新建长度字段协议默认动态数组 float32。【固定字段（按通道表提取）】适用于混合类型和明确偏移。旧非统一规则在加载时覆盖并安全保存，保留名称、单位和换算。

二进制协议说明下方先展示【帧结构】，再展示总帧长和自动计算的长度公式。内容可选中复制。动态数组按实际数据区读取通道，固定字段按表中配置提取。结构冲突会标红并阻止保存或测试。

#### 3.3.2 数据校验

提供 SUM8、XOR8、CRC8/SMBUS、CRC16/MODBUS、CCITT-FALSE、XMODEM、CRC32/ISO-HDLC。【校验算法】旁的【说明 / C 代码】打开可调整大小、最小化/最大化的说明窗口，包含各算法参数、标准自检向量、线序及校验范围注意事项和可复制的 C99 示例。示例会实际编译验证，与软件计算结果对照。请先用设备的真实报文验证规则。

数据校验从帧起点 0 开始，覆盖帧头、长度、数据与保留字节，到校验位之前结束。校验位和帧尾位于覆盖范围之外。帧末按【数据 → 尾部保留 → 数据校验 → 帧尾】排列。无帧尾时校验位位于最后。多字节校验值跟随默认大小端。可选帧头校验独立保护数据区前的头部与长度。

系统自动确定校验范围、位置和长度修正，并始终显示统一校验说明。选择无校验时隐藏算法摘要。动态数组在实时展示和协议测试中支持通道数变化，录制使用本次首帧的通道数。

#### 3.3.3 首尾分隔动态数组

首尾分隔协议默认采用 JustFloat 式动态数组。无帧头，帧尾为 `0000807F`，读取小端 `float32`，支持 1–256 通道，默认无校验。通道数由每帧实际数据区决定。通道表用于覆盖名称、单位、备注及换算，未配置通道使用系数 1、偏移 0。

| 分隔方式 | 组帧规则 |
| --- | --- |
| 仅帧尾 | 收到完整帧尾后划分帧。超长报文丢弃到下一个完整帧尾后重新同步。 |
| 仅帧头 | 等到下一帧头才输出上一帧，最后一帧暂存。生成样例时自动附加下一帧头。 |
| 帧头与帧尾配对 | 新帧头可跳过缺少帧尾的坏帧。 |

帧头和帧尾不能同时为空。数据区字节数无法整除字段宽度、通道数或帧长超限、校验失败时拒绝整段。数据、保留字节、校验值或跨字段组合可能与分隔标记冲突。分隔模式没有字节转义，CRC 无法消除分帧歧义。无帧头的初始半帧如果恰好满足结构，就无法判断是否完整。从半个帧尾开始接收时，后续首帧可能丢失。任意二进制数据优先使用长度字段与校验。

UDP 要求单个数据报提供完整边界。仅帧头模式也需要在同一数据报附加下一帧头。首尾分隔动态数组可参考 [JustFloat 式首尾分隔协议样例](WaveLink/tests/protocolfixtures/delimited_array_justfloat.json)。

### 3.4 多通道键值与设备模板

#### 3.4.1 键值分组

【多通道键值协议】每行发送一个键和值，通用模板默认三路 Ch1、Ch2、Ch3，样例为 `0:0\r\n1:1\r\n2:2\r\n`。所有配置的键收到后按通道表顺序输出一帧。

键可为数字或文本、区分大小写。新增分配未使用的数字键，增删或排序不会改写已有键。可设置重复键重启或最新值替换、未知键忽略或清空半帧、组帧超时（默认 1000 ms，0 不限制）。

已配置键的无效值、编码错误或超长行清空未完成组。重连/切换规则清空半帧。无帧序号的键值流无法完全识别丢包，严格采集建议使用含序号与校验的二进制帧。

#### 3.4.2 CBF、IR 和 RED 设备模板

在协议列表右键【新增协议 → 新增模板协议】中选择 **CBF/IR/RED 设备模板**，也可在新增协议对话框中选择多通道键值类型及该模板。

键 `0/1/2` 对应 `CBF/IR/RED`（CBF 默认单位 MHz，LED1 为 IR、LED2 为 RED）。设备默认采样率 31 Hz，使用 TCP 服务端，默认端口 4970。模板与其他协议一样可编辑、复制、导入导出，并随全局配置保存。

模板的【启用TCP服务器预设】默认勾选，可按需关闭。未连接时应用协议会选择 TCP 服务器和指定端口（可修改），不会自动开始监听。可在首次完整帧后自动分离视图。手动合并后不会每帧强制重新分屏。

旧内置 CBF 配置自动迁移为自定义模板，保留原来的设备预设、重复键替换和不限组帧时间规则。

### 3.5 样例测试与诊断

#### 3.5.1 选择协议与输入格式

右侧【协议名称】默认跟随当前打开的协议，使用未保存的编辑草稿。也可选择其他协议的已保存版本测试，不切换中间编辑项、不保存草稿、不影响连接。切换测试协议或协议类型时，自动选择文本/HEX 并生成对应样例，替换上一协议的输入、清空旧结果。配置无效时清空旧样例并提示。手动切换格式仍可用，普通参数编辑不会覆盖手工样例。各选项名称及结果表头可悬停查看说明。

测试区的【样例格式】切换会转换当前输入的表示，保留相同字节。文本支持 UTF-8、`\r`、`\n`、`\t`、`\\` 和 `\xHH`，HEX 仅接受十六进制，小写自动大写，非法输入/粘贴不插入。

二进制协议生成样例或从 HEX 转成文本时，全部字节统一显示为 `\xHH`，例如 `\x40`、`\x55`，帧尾为 `\x0D\x0A`，不再混入 `@`、`U` 等可打印字符。文本协议仍保持可读文字和短转义。以前的混合字符/转义样例仍可解析，不改变字节内容。要逐字节查看可选择 HEX。

【HEX 字节间空格】自动在每两位间插入显示空格，取消后连续展示。空格不计入数据，不需手工添加。半个 HEX 字节须补全后才能切换格式或解析。

#### 3.5.2 生成样例与模拟分包

点击【根据协议生成样例】，按右侧所选协议生成并验证一帧报文。当前项用草稿，其他项用已保存版本。自动处理前后缀、编码、字段类型/大小端、长度、帧头尾及校验，不改变协议、不发送。复杂固定条件或数值范围无法满足时提示并保留原输入，生成成功也不代表真实设备协议正确。

【分包方式】模拟整块（最多 4096 字节）、逐字节或随机 1–31 字节的接收边界，正常结果应一致。统计显示次数及大小。【停止测试】仅处理过程中出现，可取消大样例并保留已完成结果。小样例通常瞬间完成。

【新增协议 → 二进制长度字段类型协议】自带动态数组样例。右侧【样例通道数】控制生成样例的数量，用于验证不同通道数，实际接收按协议规则处理。

#### 3.5.3 结果精度与失败诊断

测试结果按来源精度展示。文本与 `float64` 保留双精度，二进制 `float32` 采用简短表示，例如将 `3.299999952316284` 显示为 `3.3`。换算后的数值也按该规则展示。不会统一裁成固定小数位，悬停可查看完整精度。仅改变测试表格显示，不修改采集、绘图、录制数值或范围验证。

解析失败时，下方红色诊断尽可能指出原始样例的字节偏移（从 0 开始）、帧内位置、预期与实际 HEX、出错通道/列号，并提示核对帧头尾、前后缀/结束符、分隔符、长度、校验、固定条件、编码或数值范围。无法确定的原因会标为“可能”，不会自动更改规则。样例结束还会检查未完成帧和缺失键值通道。这仅用于离线测试，实际设备接收仍正常等待半包。最多展示 100 条诊断，可选中复制。

### 3.6 协议切换、备份与迁移

串口、TCP 客户端/服务端、UDP 和 BLE 共用同一个当前数据协议，切换接口沿用当前选择。协议库和全局配置都只保存这一份选择。修改后自动应用到当前接口，重启后保留。Demo 使用自身生成的数据，但不另行记忆数据协议。录制、发送或连接操作期间禁止切换协议。结构变化涉及绘图历史时仍需确认，不删除磁盘录制。

协议库每次保存时会备份上一次有效内容，用于文件损坏后的恢复，并非恢复出厂设置。正常管理区不展示恢复按钮，只有加载失败时才提供恢复入口。恢复前文件会另存保留。

方案可独立导入/导出 JSON。【设置】中的全局配置备份也包含协议库与选择。全局导入提供追加、按 ID 更新、替换和跳过，是否恢复协议选择可以单独决定。只有通过验证的数值帧参与录制，CSV/WLR 回放不重复执行自定义换算。可导入的样例参见 [协议样例目录](WaveLink/tests/protocolfixtures)。

## 4. 波形查看与测量

### 4.1 主视图与独立视图

- 在【数据通道】中勾选主视图需要显示的通道。单个勾选和全选/取消全选仅控制主视图，独立视图始终显示其中的波形。点击通道颜色块可调整曲线颜色，通道的勾选状态会保存。
- 主视图支持左键拖动平移、滚轮缩放时间轴。关闭【Y 轴自适应】后，可按住 `Ctrl` 滚轮调整 Y 轴。双击波形用于测量。主视图和独立视图的悬停读数、测量点读数及差值标记会自动避让绘图区边缘，缩放或调整视图大小后仍保持在图内。【跳转至最新时刻】可回到实时数据。
- 右键点击通道可将其分离到独立视图。在独立视图右键菜单中，可合并回主视图，也可用【视图位置上移】或【视图位置下移】与相邻独立视图交换位置。独立视图较多时，绘图区会提供纵向滚动。
- 在主视图右键可选择【导入数据】和【导出当前波形】。【清空波形】位于该菜单末尾。主视图右键清空及右侧清空按钮都会先确认，再清除所有视图的历史波形和测量结果。取消会保留数据，已保存的文件不受影响，连接和录制继续。导入、导出与原有按钮相同，导出包含所有通道当前保留的历史数据。

### 4.2 实时历史与绘图背景

- 【实时历史上限】仅限制实时采集时各绘图视图共同保留的历史数据，默认 64 MB。达到上限后，软件会清理最旧的实时显示数据。它**不会裁剪离线导入的数据，也不会限制完整录制文件**。点击【暂停绘图】可暂停波形更新，再点击【继续绘图（已暂停）】恢复更新。数据接收和磁盘录制继续运行。离线导入默认展示完整时间范围。小文件完整加载，大文件自动按需浏览，所有采样点仍可访问。按需浏览的概览保留峰谷，缩放、拖动后读取对应区间的原始采样点。修改实时历史上限、滤波或分离视图均不会截掉文件里的数据，界面会区分“完整保留”“峰谷概览”和“原始采样点”。
- 主视图右键【绘图背景颜色】可分别设置主视图及所有独立视图的背景，提供【跟随系统主题】【暗黑主题背景】【浅白主题背景】及自定义颜色。选择后实时预览，确定保存、取消还原。【恢复默认】恢复跟随系统主题。设置自动记忆并随全局配置导入导出，独立视图的新建窗口也会继承。坐标文字和网格适配所选背景，通道波形配色保持原样。

### 4.3 数字滤波、频谱与信号分析

【数字滤波】提供陷波、高通和低通。底部【频谱分析】可选择通道并设置 FFT 参数，【信号分析】用于查看所选通道的统计或信号特征。分析前应核对协议和采样率设置。

滤波遇到 NaN 时保留断点并重置该通道的滤波延迟状态，下一有效值恢复处理，不影响其他通道。通用统计忽略无效值。频谱和时序/生理分析使用连续有效数据，不跨断点拼接，无有效结果时不继续展示旧数值。

### 4.4 示波器测量

在主视图或任意独立视图中右键，打开【测量】。选择【显示测量栏】后，该视图下方出现可折叠测量栏。【区间统计】快速开启 A—B 范围统计，【自动测量】快速切换为频率、周期、正/负占空比、正/负脉宽、上升/下降时间。各视图独立选择测量通道、范围、光标及项目。主视图只列出右侧已勾选的通道，独立视图列出其中的曲线，不受主视图勾选影响。

#### 4.4.1 光标定位与区间统计

- 【时间光标】拖动 A、B 竖线，显示 `T_A`、`T_B`、`Δt`、两处数值及 `ΔY`。【幅值光标】拖动 Y1、Y2 横线读取幅值差，也可同时显示两类光标。拖动光标不会平移波形。设置菜单的【精确设置光标位置】可输入坐标。时间以打开位置窗口时的最新时刻为零点，光标固定于对应的数据时间，移出视窗后可【重置光标至可见范围】。
- 默认吸附最近的真实采样点。取消【吸附采样点】后可自由定位，两点之间的数值按相邻有效采样点线性插值。没有有效值时显示 `--`。`1/Δt` 标为“间隔倒数”，只有 A、B 相隔一个完整周期时才代表信号频率。
- 【范围】选择当前可见范围或 A—B 区间。统计支持最小值、最大值、峰峰值、平均值、有效值 RMS（含直流）和总体标准差。结果表可滚动，悬停查看计算说明和完整精度。【复制结果】复制当前选中项目，设置菜单【测量项目】可增减项目。

#### 4.4.2 自动测量与数据范围

- 【自动测量阈值设置】支持自动估计或手动填写高低电平。低、中、高参考默认分别为 10% / 50% / 90%，中参考迟滞为 2%，周期变化容差为 20%。
- 频率和周期至少需要两个稳定完整周期，每周期至少包含 8 个采样间隔。脉宽可测量单个完整脉冲。若边沿只落在一个采样间隔内，无法解析真实上升或下降时间，结果显示 `--`。

测量定义参见 [Tektronix 示波器测量说明](https://www.tek.com/fr/documents/primer/setting-and-using-oscilloscope)。

使用当前保留的完整采样数据计算，滤波开启时测量滤波后的波形。不使用屏幕抽稀点，不改变采集或录制。统计忽略无效值，周期和边沿不跨 NaN、重复/倒序时间或明显时间缺口拼接。时间精度依赖数据时间轴及采样率设置。绘图已丢失或清理的数据不能通过测量补回。单次范围超过 200 万点时提示缩小范围，不静默截断。

测量设置按视图自动保存，并随全局配置导入导出。光标坐标仅在当前数据会话内保留。关闭测量栏可恢复绘图空间，清空波形会清除旧测量结果。移除测量通道时只更新该视图的测量来源。测量栏开启后，空间不足可滚动查看各视图。

## 5. 录制与离线浏览

### 5.1 开始录制

在左侧【数据存储】设置缓存路径和录制模式。建立连接后点击【开始录制】，文件将写入所选路径下的 `WaveLink_Cache` 文件夹。没有建立连接时无法开始录制。

| 录制模式 | 格式与用途 |
| --- | --- |
| 兼容模式（CSV） | 文本格式，便于其他软件直接读取。高采样率、多通道时，文件和转换开销可能较大。 |
| 高速模式（WLR） | WaveLink 二进制格式，适合高采样率、多通道或长时间录制。支持重新导入，也可使用【保存数据】转换为 CSV。 |

两种模式均支持单文件约 1 GB 自动分卷。启用【录前清空】后，开始录制时清空当前显示的波形，已有磁盘录制文件继续保留。异常退出留下的临时录制文件会在下次启动时尝试恢复。写入失败时停止录制并显示错误。

### 5.2 录制数值与通道规则

自定义协议的通道表上方可设置【录制保存数据类型】。该设置与 CSV / WLR 格式独立，适用于串口、TCP、UDP 和 BLE，只影响后续开始的录制。设置按协议保存，随独立协议和全局配置迁移。旧协议默认使用原始数值。

| 保存类型 | 保存内容 |
| --- | --- |
| 原始数值（默认） | 按字段类型和大小端解码的值，位于系数、偏移和超限 NaN 替代之前。 |
| 换算后数值 | `原始值 × 系数 + 换算偏移`，保留超限处理产生的 NaN。 |

未配置通道按系数 `1`、偏移 `0` 保存原值。两种模式都记录数值，不包含界面数字滤波。以原始值 `2534`、系数 `0.01` 为例，实时波形显示 `25.34`。原始录制保存 `2534`，换算录制保存 `25.34`。原始数值录制也不包含完整报文字节。

CSV / WLR 每次录制以开始后收到的首个有效数值帧锁定通道数。后续数量不符的帧仅跳过录制，不截取或补造通道，也不影响实时展示。状态栏以红色累计显示“录制中 · 已跳过 N 帧异常数据”，停止后清除、再次录制重新锁定并清零。真实磁盘写入失败仍立即停止。

历史变通道 CSV / WLR 文件仍可导入、合并和导出，缺失通道记为 NaN。

### 5.3 磁盘缓存与清理

【磁盘缓存上限】用于检查 `WaveLink_Cache` 的大小，并作为录制磁盘的最低安全剩余空间。实时波形历史由【实时历史上限】单独管理。

缓存目录超限时，可选择保留缓存并继续、清空缓存并继续，或打开目录自行处理。关闭提示框会取消本次录制。磁盘剩余空间不足时会提示并阻止录制。

1. 点击【清空缓存】，核对确认窗口中的缓存路径、文件数量、大小和影响。重要录制请先另存。
2. 点击【确认清空】才会删除本次列出的缓存文件，包括录制、分卷及未恢复的临时文件。操作不可撤销。取消、按 `Esc` 或关闭窗口可退出。
3. 清理范围限于当前列出的缓存文件。波形内存、缓存目录外的另存文件、子目录，以及确认期间新增或发生变化的文件均保留。录制中或其他实例使用缓存时禁止清理。

### 5.4 保存录制、导出波形与导入

| 操作 | 数据范围 |
| --- | --- |
| 【保存数据】 | 将完整录制及其分卷合并或转换为 CSV，保留文件原有的数值。 |
| 【导出当前波形】 | 保存所有通道当前保留的波形。实时数据以绘图历史为范围，离线数据包括当前视窗之外的数据。结果保留已有的换算值，并包含当前已应用的滤波。需要保留完整原始数据时，应使用录制。 |
| 【导入数据】 | 加载 CSV 或 WLR 文件进行回放和分析。离线数据完整保留，无需再次套用当前协议缩放。 |

#### 5.4.1 CSV 编码与时间轴

CSV 录制、保存数据和导出当前波形统一使用带 BOM 编码标识的 UTF-8，以便表格软件识别中文通道名称。每个录制分卷有独立标识，合并后仅保留一个标识和一行表头。名称、数据及时间戳不变。旧的无 BOM UTF-8 CSV 仍可导入，重新使用【保存数据】导出时会补上标识，原缓存文件不修改。旧文件在表格软件中显示乱码时，可选择 UTF-8 编码导入。不要把已误读的乱码另存覆盖原文件。

WaveLink 录制时保存主机接收时间。批量接收的数据导入后会重建较均匀的显示时间轴，以避免波形阶梯化。这种重建属于估算，不能替代设备提供的精确采样时间戳。

### 5.5 离线完整加载与按需浏览

#### 5.5.1 完整加载额度

在【系统设置 → 绘图显示 → 离线完整加载上限】可设置 `16–4096 MB`，默认 `256 MB`。该设置随全局配置保存及迁移。完整加载所需空间按 `采样行数 ×（通道数 + 1 个时间列）× 8 字节` 估算，同组分卷合计计算。

实际完整加载额度取设置值与当时可用物理内存的 `1/8` 中较小者。无法读取系统内存时，保护额度为 `128 MB`。滤波、绘图、索引和独立视图另占内存，程序总内存还取决于这些功能的用量。

#### 5.5.2 大文件按需浏览

超过完整加载额度时自动转为**按需浏览**，保留完整离线数据。首次扫描在本机缓存路径下建立 `WaveLink_Browse_*` 临时目录，保存精确数值和稀疏峰谷索引。内存只保留索引与当前显示区间。

- 波形概览使用峰谷索引，光标、测量、频谱与信号分析读取原始采样点。超过单次分析点数限制时会提示缩小范围。
- 【导出当前波形】会流式读取整份离线数据。滤波按原始顺序连续计算并写入独立临时缓存，浏览切换区间时保持滤波连续。
- 初次扫描和滤波需要时间和额外磁盘空间，可以取消。正常清空波形、切换数据或退出时会清理临时目录。

#### 5.5.3 导入提示与故障处理

文件超出额度时，导入结果会说明已转为按需浏览，并提示上限的设置位置。格式错误、缓存写入或索引额度不足时，保留当前波形和原始文件，显示具体原因、调整建议及“绘图显示设置”入口。可按提示提高额度、选择有足够空间且可写的本机缓存路径，或检查文件格式及分卷。索引仍过大时可整理为较小的独立文件。

## 6. 数据收发

### 6.1 接收内容的保存与复制

【保存接收】把点击时接收文本框中显示的内容保存为 TXT，默认名称为 `WaveLink_Receive_yyyyMMdd_HHmmss_zzz.txt`，可自行选择路径。文件使用带 BOM 的 UTF-8，保留当前的中文、HEX、时间戳和换行。选择文件期间新收到的内容不加入这次保存。空文本框会提示，不生成空文件。此功能只保存当前显示内容（受接收文本框历史清理限制），不替代持续录制或原始字节抓包。

接收区域第二行的【保存接收】、【复制接收】与【显示缓存】集中展示。【复制接收】可一键复制接收文本框的全部内容，保留当前的中文、HEX、时间戳和换行，不改变原内容或选区。文本框为空时会提示，并保留剪贴板原有内容。缓存说明可悬停【显示缓存】标签或下拉框查看，不额外占用工具栏空间。

### 6.2 接收显示缓存

【显示缓存】可选 1000、2000、5000 行，默认 1000 行，并随全局配置保存及迁移。行数按换行计算，末尾空行也计一行，界面自动折行不单独计数。默认字符上限为 5 万，刷新间隔为 100 ms，无换行的二进制或 HEX 数据同样受字符上限保护。

达到行数或字符上限时，仅移除最旧内容。降低行数上限会立即裁掉多余历史，提高上限无法恢复已经移除的内容。限制作用于接收显示和【保存接收】、【复制接收】可取得的历史。协议解析、状态监视、波形采集及 CSV / WLR 录制独立运行。需要保留完整数据时，请使用持续录制。

### 6.3 定时发送

【数据收发 → 定时发送】按设定周期重复发送当前发送框内容，沿用 HEX 和发送追加换行设置，默认周期 1000 ms。第一个周期结束时首次发送，运行中修改周期会重新计时。

周期自动保存，并随全局配置导入导出。开启状态不保存，重启或重连后不会自动发送。

断开、切换接口、清空发送内容、开启 Break、取消待发送、开始文件发送或发送队列拒绝时自动停止。停止后不再提交新数据，已进入发送队列的字节仍可能发出，必要时使用“取消待发送”。周期是软件计时，不保证精确的设备到达间隔。

### 6.4 文件发送

【数据收发 → 发送文件】支持图片、文档、压缩包等任意类型，选择器默认显示所有文件。串口、TCP 和 BLE 按文件原始字节分段发送。发送框的 HEX 及追加换行设置不影响文件内容，`.hex` 文本文件也按原文发送。软件不会附加文件名、长度、校验或保存指令，接收端需按约定的协议接收和保存。UDP 和 Demo 暂未提供文件发送。

进度条右侧显示预计剩余时间 `时:分:秒`，按最近实际写出或提交的字节速度估算。测速不足或长时间停滞时显示 `--:--:--`。完成、停止、失败或断开后显示 `00:00:00`。接收端是否已校验或保存文件需另行确认。

## 7. 命令交互面板

### 7.1 打开面板与发送命令

从【工具 → 命令交互面板】打开面板，保存常用命令。左键发送或切换，短按右键打开菜单，长按右键约 0.7 秒直接编辑，也可选择【编辑命令】。打开菜单和编辑不会触发发送。菜单提供新增、复制、排序和删除，并按命令类型列出发送操作。

| 命令类型 | 右键发送操作 |
| --- | --- |
| 普通命令 | 发送一次。 |
| 定时命令 | 发送一次、开始或停止定时发送。发送一次不改变当前定时状态。启动循环时先立即发送一次，再按周期重复。停止后，已排队字节仍可能发出。 |
| 开关命令 | 切换并发送、指定状态 0 或 1，也可重发当前状态。发送入口接纳命令后才更新显示。 |
| 滑条命令 | 发送当前值或恢复默认值并发送。列表模式可直接选择项目，发送对应的实际内容。通过菜单可重发同一个值。 |

【数据收发】区的定时发送在一个周期后首次发送。滑条拖动时会抑制重复值。

发送沿用当前 HEX、前后缀及追加配置，仍受连接、Break、队列等现有条件约束。面板内有独立的使用说明。

### 7.2 开关命令

命令类型支持按钮、滑条和**开关命令**。开关与普通按钮尺寸相同，采用滑块式外观，只有状态 0/1。每个状态分别设置命令、状态名称和颜色，默认状态名称为关闭/开启，也可用于模式 A/B。

点击发送另一状态的命令，只有成功提交到当前接口发送队列后才切换显示。未连接、Break 占用或队列拒绝时状态不变。显示仅表示软件请求，不代表设备已确认执行。

HEX 与追加方式共用，HEX 只限制命令及自定义追加，状态名称和说明不发送、可任意输入。两个状态均可选透明颜色并适配主题。命令输入自动增高，超过 10 行内部滚动。

开关不定时轮换。启动、重连、导入、切换面板或主题不会自动发送。保存默认状态、不保存运行状态，重启或重新载入按默认状态展示。全部配置随面板及软件整体配置导入导出。

### 7.3 文本、HEX 与编辑说明

文本命令以 UTF-8 发送，接收框的 UTF-8/GBK 选项不改变发送编码。键入 `\r\n` 不会自动转义，实际换行请用追加选项，或在命令编辑框中用 Ctrl+Enter / Alt+Enter 插入 LF。

常规滑条即使勾选 HEX，变化数值仍按十进制文本发送，不自动编码为二进制整数/浮点数。例如 HEX 前缀 `AA`、数值 20（小数位 0）发送 `AA 32 30`。需要离散二进制参数时可用列表模式填写实际字节。

命令/前缀及附加命令输入框随内容自动增高，最多显示 10 行（含自动换行）。超过 10 行后才显示内部滚动条，删减内容后自动收回。编辑窗口高度不足时可通过表单整体滚动条查看其他设置，底部保存/取消按钮保持可用。

命令、附加命令及自定义追加输入框在 HEX 模式下，支持粘贴带空格、换行或制表符的多行字节，也支持 `5A5A5A` 这样的连续内容，自动显示为大写并按字节加空格。空白不发送。支持快捷键及右键粘贴、复制、剪切和撤销。含其他字符的粘贴不会改变原内容，不接受 `0x` 前缀、地址或注释。保存时检查每个字节必须完整两位。

### 7.4 面板管理与说明显示

左侧命令面板列表的项目和空白处均可右键打开菜单，支持新增面板、导入面板和导出所有面板。右键某个项目时，重命名、复制、删除、查看说明、导出当前面板和上移/下移均针对该项目。空白处这些操作置灰，不改变之前选中的面板。没有面板时，“导出所有面板”不可用。

左侧面板列表右键可【复制面板】，保留说明、命令和布局，副本放在原面板下一行，名称自动添加 `_1`、`_2` 等后缀。副本不会自动启动定时发送，原面板的运行状态不受影响。

按钮、滑条和开关命令均可填写“说明”（原“备注”），不参与发送。鼠标悬停在命令上只展示说明内容，保留多行和特殊字符。没有填写时显示“暂无说明”。提示框适配浅白、暗黑主题。旧配置中的命令备注会自动作为说明读取，独立面板及全局配置导入导出仍保留该内容。面板名称和面板说明统一在右上角【面板设置】中修改，旧面板备注仍兼容读取。左下角【导出所有】导出全部面板。右键列表可导出单个面板。

悬停说明会根据鼠标所在屏幕的可用空间自动换行，连续长串字符也会折行。能容纳时完整显示，过长时仅预览前部并提示右键编辑查看完整说明，避免提示框超出屏幕。原始说明始终完整保存，编辑窗口内可滚动查看全部内容。

### 7.5 备份与旧配置修复

每个命令面板都有独立的【编辑布局】入口。选择【自定义分行】后，可新增行、拖动命令卡片或整行上移／下移。每行最多列数（1–10）在布局编辑器和面板设置中共用，滑条独占一行，只能拖到空行。点击【保存】应用，窄窗口可横向滚动。编辑器中的卡片用于排版，点击和拖动都不会发出指令。

独立命令面板 JSON 备份面板、命令与布局，不包含设备连接参数、自定义协议库和软件全局偏好。整体迁移请使用“设置”中的导出配置 / 导入配置。运行中的定时发送、开关当前状态和滑条当前值不会作为自动发送任务恢复。

旧版命令配置中缺少可补充的开关字段时，软件会先完整备份原文件再自动兼容。若开关的两段命令内容缺失，会保留该命令并标记“待补全 · 禁止发送”，其他面板仍可使用。右键编辑并填写两个状态的命令后保存即可恢复。

配置无法读取或被其他实例修改时，窗口上方提供“一键修复”，优先修复当前文件，无法修复时尝试最近有效备份。原文件另存为 `cmd_panels.json.before-repair-日期-标识.json`，正常保存还会维护 `cmd_panels.json.bak`。

无法恢复时保留原文件，不用空配置覆盖。导入独立面板和全局配置使用相同的兼容规则。缺失且无备份的命令正文需要重新填写。

## 8. 状态监视

### 8.1 创建面板与选择来源

从主窗口【设备交互 → 状态监视面板】或【工具 → 状态监视面板】打开。首次使用先新增面板，再添加监视项。同一面板可同时监视通道数值与接收文本。面板总开关与面板设置同步，重新启用时保留各监视项原有的启停设置。

在状态监视面板点击【编辑布局】，可分别为各面板设置自动排列或自定义分行。拖动监视卡片调整行内和跨行顺序，也可以整行上移／下移。每行最多列数（1–8）在布局编辑器和面板设置中共用。保存后的行顺序随面板复制和配置导出，窄窗口可横向滚动查看。

| 来源 | 配置方式 |
| --- | --- |
| 通道数值 | 默认使用原始值，可改为换算后数值。该选择独立于录制方式。支持数值映射、位段解析、阈值区间，可设置生效延迟、回差和超时。 |
| 接收文本 | 支持完整匹配和前缀匹配，可配置编码、结束符、首尾空白和大小写。UDP 可使用整报文。同一面板的监视项可复用文本来源。Raw 可监视真实接收文本，Demo 没有设备文本反馈。 |

二进制与文本混传需有可靠的外层边界，再按规则判断设备反馈。状态监视与命令发送、开关状态及数值录制分别运行。

### 8.2 协议绑定与时间设置

- 【锁定协议及结构】校验协议标识和结构，避免切换协议后误读通道。绑定统一在【面板设置】中配置。新面板默认锁定当前有效数值协议，监视项继承绑定。当前没有数值协议时默认跟随。旧面板绑定一致时自动迁移，混合绑定保留原行为并提示统一。
- 【选择协议】按系统协议和自定义协议分组，JustFloat 的大小端分别列出。Raw 没有数值通道，因此不可选。协议及来源通道下拉最多显示 10 项。
- 选择协议或点击【绑定主界面当前协议】会更新本面板的通道数值监视绑定。来源显示所选协议的通道名称，通道编号和主界面采集协议保持原设置，文本监视独立。两种绑定方式均按序号查找。选择【跟随当前协议的通道序号】时，由用户核对通道含义。
- 锁定的协议名称单独显示并可复制。协议缺失、当前使用其他协议或结构发生变更时会提示。旧结构显示“保留结构”，需明确选择列表中的最新协议才会更新绑定。编辑项显示继承的协议及匹配状态，通道超出已知范围时也会提示。

保持时间为条件持续满足后的生效延迟，设为 0 时立即生效。有效期为无新有效数据的超时期限，新建项默认“不自动过期”（0 ms），已有项沿用已保存期限。设备断开时状态立即失效。支持时间预设和自定义毫秒数。

### 8.3 规则测试、卡片与编辑

- 规则编辑窗口可生成样例、手动测试解析或模拟分块输入，测试独立于实时状态和发送。卡片显示状态及等待、未知、异常、超时、断线等信息。
- 规则颜色列使用色块，棋盘格代表默认或透明。双击色块可打开中文颜色窗口，点击【拾取屏幕颜色】下方的【使用透明颜色】，保存监视项后恢复主题默认显示，卡片文字仍可见。
- 严重程度以蓝色“提示”、橙色“警告”、红色“错误”展示。“无”不显示标识。严重程度只用于标记卡片。
- 左键启停监视项，短按右键打开菜单，长按右键编辑，拖动可排序。操作不影响设备连接。编辑中 `Ctrl+S` 仅保存，【保存监视项】保存并关闭，【关闭编辑】退出未提交的修改。规则增删和排序支持 `Ctrl+Z`，输入文字时优先撤销输入。

### 8.4 实时状态与事件提示

在【解析来源】下方选择监视模式。已有配置默认仍为实时状态，按最新数据更新。事件提示适合单帧标记、瞬时故障和一次性反馈。后台在绘图合并前逐帧判断，事件模式不使用生效延迟或恢复回差。

新建事件提示默认保持至手动清除或下一事件（0 ms），也可定时清除。新事件立即替换卡片提示，触发记录进入有限历史。卡片显示触发次数和屏蔽条数。右键【清除事件提示】只清除本项显示，保留次数和历史。断线重连、改变解析配置或重启后重新累计次数。仅修改名称、说明或颜色等展示信息不会重置监视状态。

#### 8.4.1 事件屏蔽

最多设置 64 条屏蔽条件，任一启用条件命中即静默。数值来源支持【固定数值】与【数值区间】，文本来源还支持【固定文本】。新建数值项切到事件模式时默认屏蔽 0，可以删除、修改或停用。

- 数值条件在位段提取前对所选原始或换算值生效。区间包含上下限，固定数值精确比较，浮点数建议用区间。
- 文本条件作用于完整分帧、解码及空白处理后的正文，大小写遵循来源设置。用于文本的数值条件要求整条正文可解析为有限十进制数，支持科学计数法。条件使用固定值和区间，无需表达式或正则脚本。
- 屏蔽和未匹配内容不会覆盖或延长已有提示。屏蔽仅作用于该监视项的事件判断，接收显示、协议解析、绘图、录制和其他监视项独立运行。NaN / Inf、缺少通道和断线不能被屏蔽。

#### 8.4.2 重复触发与数据静默超时

| 重复触发选项 | 行为 |
| --- | --- |
| 进入匹配状态时触发 | 适合脉冲标志。连续命中同一数值、位段、区间或文本规则只触发一次。遇到屏蔽或未匹配内容后重新等待进入。提示过期或手动清除后，相同输入持续出现时不会立即重新触发。 |
| 每次匹配均触发 | 每条匹配反馈都视作独立事件，连续匹配会累计次数并重置提示时间。 |

【数据静默超时】与提示保持时间独立。有效数值帧或合法完整文本消息均表示来源仍活跃，包含屏蔽及未匹配内容，且不因此延长提示。数据超时、断线和异常优先显示，文本队列遗漏反馈仍会警告。

#### 8.4.3 配置单帧事件示例

假设 500 Hz 通道通常为 0，偶尔有单帧值 10 或 20。

1. 选择【通道数值 → 事件提示】，锁定对应协议与通道，使用原始数值。
2. 添加数值映射 `10 → 状态A`、`20 → 状态B`，保留固定数值 0 的屏蔽条件。
3. 重复触发选【进入匹配状态时触发】，保持时间设为 2000 ms。后续 0 不会覆盖提示，下一次 10 或 20 可重新触发。

同一卡片显示最新事件。需要同时保留两种提示时，可分别创建监视项。解析测试使用同一规则并显示触发和屏蔽计数。生成样例时跳过能识别的屏蔽值，无法生成时可手动输入。模式及屏蔽条件可随本机、面板和全局配置保存，兼容读取旧格式。

### 8.5 记录、独立备份与全局迁移

关闭窗口后仍继续监视，停用面板或监视项才停止相应判断。状态记录在内存中最多保留 2000 条，默认记录变化，文本可记录每次匹配。筛选只影响显示，导出包含全部保留记录。清空记录保留触发和屏蔽次数及卡片提示。记录不跨重启保存，来源诊断也有数量上限。

面板自动保存，记忆选中项及窗口位置。配置异常时保留原文件，可从有效备份恢复。

- **独立 JSON**支持【导出所有】或右键导出当前面板。导出不能覆盖内部配置、备份或窗口偏好文件。独立导入仅迁移面板内容，协议库和窗口位置需用全局配置迁移。追加时重新分配 ID 并避免面板重名，覆盖时替换全部状态面板。
- **全局配置**包含面板、规则、共享文本来源和窗口偏好，导入可单独选择覆盖、追加或跳过。旧配置缺少状态面板时保留本机内容。追加会为面板、监视项及文本来源分配新 ID，并避免重名。协议按追加导入时，导入的监视项同步映射绑定。缺失或过期的结构绑定仍需手动处理。导入失败会恢复原设置和配置文件，事务中断时在下次启动恢复。

## 9. 系统设置与配置迁移

### 9.1 打开系统设置

打开【设置 → 系统设置(O)】，也可在【设置】菜单中按 `O`。左侧分类依次为【界面设置】、【数据收发】、【绘图显示】、【软件更新】，默认打开【界面设置】。接收区的【接收设置】直接进入【数据收发】。

| 分类 | 设置 | 可选值与默认值 |
| --- | --- | --- |
| 界面设置 | 恢复默认布局时的下方区域高度占比 | 20%–50%，默认 30% |
| 数据收发 | 接收缓存行数 | 1000、2000、5000 行，默认 1000 行 |
| 数据收发 | 接收缓存字符上限 | 1–25 万字符，仅整数。建议使用默认的 5 万字符（50,000 字符） |
| 数据收发 | 接收刷新间隔 | 50、100、150、200、250、300、500、1000 ms，默认 100 ms |
| 绘图显示 | 波形目标刷新率 | 5、10、15、20、25、30、40、50、60 帧/秒，默认 30 帧/秒 |
| 绘图显示 | 离线完整加载上限 | 16–4096 MB，默认 256 MB |
| 软件更新 | 启动后自动检查 | 默认开启，每天最多检查一次 |

高速接收建议保持默认或降低接收缓存。目标刷新率只作用于绘图刷新，设备采样率、Y 轴自适应及录制独立。

点击【应用】或按 `Ctrl+S` 保存并留在当前窗口。点击【保存并关闭】保存后退出。【恢复本页默认】只更新当前页草稿。设置自动记忆，可随全局配置迁移。旧配置缺少新增项时采用默认值，旧的 10000 行选项迁移为 5000 行。

### 9.2 界面布局与主题

顶部【数据收发模式】暂时只显示参数设置和数据收发面板，再次点击可恢复之前的布局。面板可折叠，也可拖动调整大小。点击【恢复默认布局】可恢复标准排列。支持暗黑和浅白主题。

下方数据收发、频谱分析、信号分析区域的默认高度占比为 30%，上方约为 70%。比例以当前窗口工作区为基准，菜单、工具栏和状态栏不计入，实际高度受控件最小尺寸限制。旧版按屏幕高度 25% 且限制在 220–320 像素的规则已替换。

点击【恢复默认布局】或首次启动且没有已保存布局时才应用该比例。手动布局会记忆，数据收发模式内部的接收与发送分割比例独立保存。高度占比可随全局配置迁移。

### 9.3 全局配置导入和导出

通过【设置】菜单中的【导出配置】和【导入配置】备份或迁移软件配置。全局配置包含软件设置、连接参数、协议库和选择、命令面板及状态监视面板。各面板和协议也可按各自的功能独立导入导出。

缓存路径仅在本机自动保存，不包含在【导出配置】中。【导入配置】保留当前电脑的缓存路径，也会忽略旧配置中携带的路径。新电脑未设置时使用本机默认目录，可在【数据存储】重新选择。缓存上限、录制模式等其他设置仍正常导入、导出。

## 10. 软件更新

### 10.1 检查与安装更新

【帮助 → 版本信息】提供当前版本、检查更新、更新说明和安装包下载。系统设置的【软件更新】可开关启动后自动检查（默认开启，每天最多一次），并纳入全局配置导入导出。

未配置发布地址/公钥时明确提示，保留手动下载。不会连接示例服务器。

下载与采集录制互不打断，安装需要先结束录制、停止发送并断开设备，确认后备份配置并退出。安装版覆盖升级，不先卸载、不清理录制缓存。便携/开发目录不自动覆盖安装。更新验证签名、大小与 SHA-256。失败不安装。发布工具与接入说明见 [在线更新发布指南](deploy/update/README.md)。

### 10.2 生成发布文件

在线更新发布支持一次生成密钥，并在后续构建时自动配置。已有用户目录 `.wavelink-release` 中的发布密钥后，运行 `deploy/setup/Build_Setup_Version.bat` 会自动验证密钥、补齐公开渠道和本地发布配置，再按本次版本生成 GitHub 下载地址、签名 `latest.json` 及当前版本更新说明。

默认使用 `yffdd/wavelink`，`v{version}` 自动替换，不需要逐版手工修改地址或额外维护说明文件。已有自定义配置和私钥不会被覆盖。

工具只生成本地文件，不自动上传或发布 GitHub Release。

## 11. 常见问题

### 11.1 串口无法打开

检查设备是否在线，确认端口正确并退出占用它的其他串口软件。

### 11.2 连接后没有波形或频谱异常

先在【数据收发】确认收到数据，再核对协议、通道勾选和采样率。普通文本或 HEX 调试使用 Raw。绘制数值波形时需选择与设备数据匹配的数值协议。

### 11.3 录制文件比当前波形更长

绘图历史达到内存上限后会丢弃最旧的实时显示数据。完整录制仍持续写入磁盘。

### 11.4 无法开始录制

确认连接已建立、缓存路径可写，并查看缓存超限或磁盘剩余空间提示。

### 11.5 查看操作说明和诊断日志

打开主窗口右上角的帮助中心，查看使用说明、协议文档和程序调试日志。
