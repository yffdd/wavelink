WaveLink

WaveLink 是一款面向串口调试、网络数据收发和多通道波形分析的 Windows 上位机。它可以接收并显示文本或波形数据，提供数字滤波、频谱与信号分析、常用命令交互，接收数据状态监视，以及 CSV / WLR 数据录制和离线导入。没有设备时，也可以使用内置 Demo 数据熟悉界面。

获取与启动

- 安装版：运行发布的 Setup 安装程序，按向导完成安装后启动 WaveLink。
- 便携版：解压完整的便携文件夹并运行 WaveLink.exe；如果取得的是单文件便携版，可直接运行该程序。不要只从多文件便携版中单独复制 WaveLink.exe，它还需要同目录的依赖文件。
- 从源码构建：工程入口位于 WaveLink/CMakeLists.txt，需要 Qt、MinGW 和 CMake。发布脚本及其外部工具配置见 deploy/readme.md。

首次启动后，建议先选择数据接口和数据协议，再建立连接。主窗口右上角的“?”可以打开帮助中心，查看更详细的协议说明、使用指南和程序诊断信息。

快速开始

1. 在左侧【参数设置】选择数据接口，顺序为：串口、TCP 客户端、TCP 服务端、UDP 用户数据报、BLE 低功耗蓝牙、Demo 数据。悬停“数据接口”可查看各接口的简要用途，下拉列表各项也有对应提示；设备连接区的配置名称提供简短说明，输入控件保留更详细的操作或安全提示。
2. 根据设备实际发送的内容选择数据协议。普通文本调试选 Raw（文本/Hex）；逗号分隔的数值行选 FireWater（CSV 文本）；二进制浮点数据选 JustFloat，并核对大小端。多行键值数据可在 自定义协议 中新增 多通道键值协议；专用设备可从 CBF/IR/RED 模板 创建（键 0、1、2 对应 CBF、IR/LED1、RED/LED2）。协议旁的“?”提供格式和示例。
3. 串口模式下选择端口并核对波特率、数据位、校验位和停止位；TCP / UDP 模式按界面设置地址和端口。然后点击连接或打开按钮。Demo 模式则配置波形参数后点击【启动 Demo】。
4. 在底部【数据收发】面板查看接收内容、输入并发送数据；如果输入的是数值波形协议，也可以在主视图和右侧【数据通道】面板观察曲线。

如果串口打开失败，请检查设备是否仍在线，以及该端口是否被其他串口软件占用。若收到的是普通文本，却出现异常波形或频谱，先检查是否误选了数值协议。

串口参数末尾提供 DTR / RTS 复选框，默认关闭并自动保存。连接前设置供下次打开使用，连接后切换在后台应用；这不是 RTS/CTS 硬件流控，普通数据收发不一定需要开启。部分开发板会因控制信号变化复位或进入下载模式，请按设备说明使用。驱动不支持时会提示，未确认的信号在当前连接中显示为半选并禁用，不会仅因此中断接收和录制。

Windows 下，在串口句柄打开后、报告连接成功前合并应用 DTR/RTS 并释放 Break；关闭前再次核对用户请求的控制状态，不恢复打开前的旧串口设置。相同且已确认的状态不重复切换；驱动未确认时不通过逐个切换控制线来盲目重试。ESP32 等使用控制线自动复位的设备，普通调试应选择无流控并按需释放 DTR/RTS。取消勾选是请求释放信号，不代表能阻止驱动在打开/释放句柄瞬间产生电平变化，也不保证所有板子完全不复位，仍需实机核对。

“停止位”下方的 流控 可选择“无流控（默认）”或“硬件流控（RTS/CTS）”，设置自动保存、连接期间不能修改。硬件流控需要转换器、设备和 RTS/CTS 接线均支持；开启后 RTS 改由驱动自动控制，切回无流控时恢复原来的手动 RTS 设置。CTS 未就绪时显示等待和待发送大小，接收及录制继续；队列最多 256 KB 或 1024 条发送请求，满后拒绝新命令并停止命令循环。文件发送按写入完成情况推进，不会仅因为读到文件末尾就显示完成，也不会混入其他命令。取消待发送或停止文件发送时丢弃软件队列中的数据，不自动重发；仅在软件队列等待可保留连接，已有未完成写入进入驱动时则安全断开串口并停止录制，弹窗明确提示。已提交到驱动或硬件的少量字节仍可能到达，无法撤回；串口写入完成不等于设备业务确认。

下方的 Break 行用于特殊设备的发送线控制：点击【发送】按设定时长短时保持后自动释放；勾选【保持】则持续保持，取消勾选或点击【释放】结束。每次启动、重新连接都默认释放，只保存时长，不保存开启状态。Break 不是发送 0x00，普通调试无需开启；执行期间普通发送不可用、命令循环停止，文件发送期间不能开启。驱动不支持会提示并禁用此功能；无法确认释放时安全关闭串口。它不是精确定时的 LIN/DMX 协议发送功能。

TCP 网络连接

TCP 客户端分别设置远端 IP/端口和本机 IP/端口。远端填设备的实际地址或主机名，端口范围 1–65535；不要将 0.0.0.0 用作远端 IP。本机 IP 默认 0.0.0.0，由系统选择出口地址；本机端口默认 0，由系统自动分配。需要固定源地址或端口时，填写本机已有的 IP 和未被占用的端口；连接成功后下方显示实际本机 IP、端口，不会把随机分配的端口写回设置。指定非零本机端口并使用主机名时，0.0.0.0 选择 IPv4，:: 选择 IPv6。

TCP 服务端的监听 IP 可编辑，也可从下拉框快速选择 0.0.0.0、127.0.0.1 或当前本机 IPv4 地址。默认 0.0.0.0 监听所有本机 IPv4 地址，127.0.0.1 仅接受本机连接；指定网卡 IP 时只在该地址监听。IPv6 地址可手动输入，:: 监听所有本机 IPv6 地址。监听端口默认 4970。仅开启服务器不代表已有客户端，需等待客户端接入后才能发送。

这些网络参数会自动保存，并包含在【设置 → 导出配置/导入配置】中；连接或监听期间不可修改。导入后立即更新参数，但不会自动建立连接。IP 无效、不属于本机、端口被占用或远端连接失败时明确提示，不会悄悄回退为其他地址或随机端口。设备 TCP 使用直连，不使用系统 HTTP/SOCKS 代理；系统代理设置本身不会改变。监听全部网卡可能允许局域网其他设备接入，请按需选择网卡，并核对 Windows 防火墙权限。

UDP 数据收发

【数据接口】中的 UDP 位于 Demo 数据前，不区分客户端与服务端。本机 IP 默认 0.0.0.0，监听所有本机 IPv4 地址；可下拉选择或手动输入本机地址，IPv6 可手动输入 :: 或具体地址，须与远端地址类型一致。本机端口默认 4970，也可设为 0 自动分配；打开后显示实际监听地址和端口，自动分配的端口不写回设置。设备应向电脑的实际网卡 IP 及此端口发送，而不是向 0.0.0.0 发送。

仅接收时，将远端 IP 留空、远端端口设为 0。需要发送时，同时设置远端单播 IP 和端口（1–65535）。勾选【仅接收远端数据】后，只接收源 IP 和源端口均匹配的数据；未设置远端时接收所有来源。建议一个监听端口只对应一台波形设备。当前只提供单播收发，不支持主机名、广播或组播。

点击【打开 UDP】后显示“UDP 监听中”，这不代表远端在线。支持 Raw 文本/HEX、命令面板、定时发送、现有内置/自定义协议绘图和 CSV/WLR 录制。每个 UDP 数据包独立解析，一包可含一帧或多帧；文本需带结束符，键值协议需在同一包内包含完整通道组，不跨包拼接残缺帧。JustFloat 保留同源连续帧的通道数验证规则。单次发送对应一个数据包，最多 65507 字节，不会自动拆包；实际建议控制包长、避免网络分片。

UDP 可能丢包、乱序或重复，录制仅保存实际收到且成功解析的数据，不会补回网络丢包。重要采集建议设备携带连续序号及校验，或使用 TCP；发送计数表示已交给本机系统，不代表远端收到。当前不提供 UDP 文件发送。UDP 参数独立自动保存，支持全局配置导入导出；重启/导入不会自动开启监听。绑定失败或收发错误会明确提示并停止相关操作，不自动换端口或重发。请核对 Windows 防火墙的 UDP 入站权限。

自定义数据协议

在【参数设置 → 数据协议】先选择【自定义协议】，再点击蓝色【⚙ 管理自定义协议】按钮（仅选择自定义协议时显示）。点击【新增协议】，先选择文本分隔、二进制固定长度、二进制长度字段、二进制首尾分隔或多通道键值类型，再配置字段名称、单位、换算规则和校验，用样例进行解析测试后点击【保存协议】或按 Ctrl+S。新草稿立即出现在列表并选中，名称随编辑实时更新；放弃新草稿会移除列表项，放弃已有协议的修改则恢复保存版本。回到主界面选择【自定义协议】或更换具体协议，会自动应用；管理窗口不提供应用按钮。没有可用协议时会提示新建或导入，并阻止开启连接。

文本配置按固定前缀、固定后缀、分隔方式、分隔符、结束符排列，前缀与后缀可空。将鼠标悬停在配置项名称或表头可查看说明。结束符、二进制帧头/帧尾及固定字节条件只接受十六进制字符和分隔空白，小写自动转为大写；含非法字符的粘贴不改变原内容。每字节需两位，不填写 0x，保存时仍校验完整字节及帧规则；普通文本前缀、后缀和分隔符不受 HEX 限制。

管理窗口采用三栏布局：左上协议列表、左下管理操作，中间协议配置，右侧样例测试；各栏可拖动调整宽度，内容过长可滚动。管理区仅保留新增、删除、导入、导出所选、导出全部及使用说明；使用说明采用分类导航、可缩放阅读窗口，支持主题适配、滚动和选中复制；删除支持 Ctrl/Shift 多选，确认后统一处理。无校验时隐藏算法摘要；统一校验说明始终显示，范围、位置及长度修正由系统计算，不提供手动范围入口。协议列表右键提供复制、重命名、排序等快捷操作及当前协议自己的【协议说明】；复制紧跟原项，名称依次追加 _1、_2 等后缀，不会自动选择副本用于实时采集。

【通道配置】文本协议自动读取全部数值列，表内只需配置需要自定义名称、单位或换算的列，列号从 0 开始。输出先按表格顺序排列已配置通道，再按原列顺序追加未配置列；后者默认命名为“ChN”（N 为原列号 + 1）、无单位、保留原始数值。通道表可留空；配置 2 路时输入 4 列仍读取 4 路，测试和实际接收一致。每帧最多输出 256 路，空列、非有限/无效数值或超限会拒绝整帧，不静默截断。CSV/WLR 每次录制以开始后收到的首个有效数值帧锁定通道数；后续数量不符的帧仅跳过录制，不截取或补造通道，也不影响实时展示。状态栏以红色累计显示“录制中 · 已跳过 N 帧异常数据”，停止后清除、再次录制重新锁定并清零。真实磁盘写入失败仍立即停止。

二进制协议仍按表内字段的数据区偏移、类型和大小端提取；换算值为“原始值 × 系数 + 换算偏移”。新增通道默认名称为“Ch1、Ch2……”，已有和导入的名称保留。大小端的“默认”表示继承协议设置。【固定字节条件】可筛选命令码或报文类型，例如要求完整帧偏移 2 为 01；全部条件匹配才接受，可留空，不代替校验。

通道表末尾的【备注】默认为空，可填写中英文、数字和符号（单行，最多 1024 个字符），随协议保存、复制以及独立协议/全局配置导入导出，不参与数值解析或换算。单位同样可自由填写。数据偏移、文本列号及数组序号只接受非负整数；系数、换算偏移、最小/最大值只接受有限数值，支持负数、小数及科学计数法，小数点使用英文句点，不接受中文或其他非数字内容。最小/最大值可留空，系数和换算偏移不可留空。键值协议的【通道键】仍支持文本，不受偏移输入限制。

新建协议默认名称分别为“文本分隔协议”“二进制固定长度帧协议”“二进制长度字段帧协议”“二进制首尾分隔协议”“多通道键值协议”，重名自动加 _1、_2 等后缀。测试结果按来源精度简洁展示：文本/float64 保留双精度，二进制 float32 避免扩展后的长尾，例如 3.299999952316284 显示为 3.3，换算后的数值也一并处理。不会统一裁成固定小数位，悬停可查看完整精度；仅改变测试表格显示，不修改采集、绘图、录制数值或范围验证。

通道名称留空时，保存协议自动补为 Ch1、Ch2…；文本未配置列使用 ChN（N 为原列号 + 1）。CSV、WLR 录制及波形导出保存对应名称，导入后通道列表、波形和分析选择恢复文件中的名称；已有名称不覆盖。CSV 支持中文名称及逗号/引号转义；旧 WLR 无名称元数据时使用默认 ChN。

新建首尾分隔协议默认使用 JustFloat 小端帧尾 0000807F，其他四种类型的默认结束符/帧尾为 0D0A。二进制协议说明下方第一行展示【帧结构】，随后展示总帧长和系统自动计算的长度公式；内容可选中复制。动态数组按实际数据区长度读取全部通道；固定字段仅提取表中配置的数值。

【多通道键值协议】每行发送一个键和值，通用模板默认三路 Ch1、Ch2、Ch3，样例为 0:0\r\n1:1\r\n2:2\r\n；所有配置的键收到后按通道表顺序输出一帧。键可为数字或文本、区分大小写；新增分配未使用的数字键，增删或排序不会改写已有键。可设置重复键重启或最新值替换、未知键忽略或清空半帧、组帧超时（默认 1000 ms，0 不限制）。已配置键的无效值、编码错误或超长行清空未完成组；重连/切换规则清空半帧。无帧序号的键值流无法完全识别丢包，严格采集建议使用含序号与校验的二进制帧。

在协议列表右键【新增协议 → 新增模板协议】中选择 CBF/IR/RED 设备模板；也可在新增协议对话框中选择多通道键值类型及该模板。键 0/1/2 对应 CBF/IR/RED（CBF 默认单位 MHz；LED1 为 IR、LED2 为 RED）；设备默认采样率 31 Hz，使用 TCP 服务端，默认端口 4970。模板与其他协议一样可编辑、复制、导入导出，并随全局配置保存。模板的【启用TCP服务器预设】默认勾选，可按需关闭；未连接时应用协议会选择 TCP 服务器和指定端口（可修改），不会自动开始监听。可在首次完整帧后自动分离视图；手动合并后不会每帧强制重新分屏。旧内置 CBF 配置自动迁移为自定义模板，保留原来的设备预设、重复键替换和不限组帧时间规则。

通道最小/最大值用于校验换算后的数值，边界值允许、留空不限制，与绘图 Y 轴范围无关。新建全部二进制及多通道键值协议的【通道超限处理】默认“超限通道标记为 NaN，其他通道保留”；文本分隔默认拒绝整帧，已有选择不变。NaN 模式排在第一项，拒绝整帧排在第二项。超限通道在绘图/分析及当前波形导出中记为 NaN；录制选择原始数值时保留真实读数，选择换算后数值时保存 NaN，不裁剪到边界。拒绝整帧模式、无效格式、原始 NaN/Inf、换算溢出及帧结构/校验错误仍不生成数值录制帧；如需保存超范围读数，请使用 NaN 模式并选择原始数值，或放宽范围。

新建协议默认无校验，通道系数为 1、偏移为 0（无缩放）；已有协议和独立教学示例的校验及系数不改动。二进制新增通道的偏移接在前一字段末尾，例如 int16 + float32 后是 6；改变类型、删除或移动通道后，按顺序及实际宽度从 0 连续重算。通道表完整向下展开，使用协议配置整体滚动条查看；最大化时各配置行仍保持正常间距。

新建固定长度二进制协议默认开启【数据区与通道自动关联】：修改通道数量/类型更新固定数据区字节数；增大数据区时，每个未配置的完整 4 字节补为 float32 通道（ChN、系数 1、无单位），不足 4 字节标明为保留字节，不猜测数据类型。缩小会删掉无法完整容纳的通道，需先确认，取消则保留原配置。固定总帧长、变长最小总帧长和末尾校验位置同步调整；选择设备长度字段的含义后，系统自动计算单位与修正值。最多 256 路，更多完整字段不能静默截断。已有/导入的特殊布局保持手动模式和原偏移；需要联动时主动勾选，也可关闭联动手动配置保留字节。

滤波遇到 NaN 时保留断点并重置该通道的滤波延迟状态，下一有效值恢复处理，不影响其他通道。通用统计忽略无效值；频谱和时序/生理分析使用连续有效数据，不跨断点拼接，无有效结果时不继续展示旧数值。

右侧【协议名称】默认跟随当前打开的协议，使用未保存的编辑草稿；也可选择其他协议的已保存版本测试，不切换中间编辑项、不保存草稿、不影响连接。切换测试协议或协议类型时，自动选择文本/HEX 并生成对应样例，替换上一协议的输入、清空旧结果；配置无效时清空旧样例并提示。手动切换格式仍可用，普通参数编辑不会覆盖手工样例。各选项名称及结果表头可悬停查看说明。

长度字段支持 1/2/4 字节无符号长度和帧长上下限。只需选择【数据区字节数】【整帧字节数】，动态数组还可选择【通道数量】；总帧长修正由系统根据总帧长、头尾、数据和校验配置计算，不再手动设置。固定字段模式的长度开销为最小总帧长减去固定数据区字节数。新建长度字段协议默认动态数组 float32；【固定字段（按通道表提取）】适用于混合类型和明确偏移。旧非统一规则在加载时覆盖并安全保存，保留名称、单位和换算。

提供 SUM8、XOR8、CRC8/SMBUS、CRC16/MODBUS、CCITT-FALSE、XMODEM、CRC32/ISO-HDLC；【校验算法】旁的【说明 / C 代码】打开可调整大小、最小化/最大化的说明窗口，包含各算法参数、标准自检向量、线序及校验范围注意事项和可复制的 C99 示例。示例会实际编译验证，与软件计算结果对照。请先用设备的真实报文验证规则。

所有二进制数据校验统一从帧起点 0 开始，覆盖到校验位之前，包含帧头、长度、数据及保留字节；不包含校验位自身和帧尾。布局为【数据 → 尾部保留 → 数据校验 → 帧尾】；没有帧尾时校验位是整帧最后的字节，多字节校验值跟随默认大小端。可选帧头校验单独保护数据区前的头部与长度。摘要第一行展示帧结构，之后展示总帧长；配置冲突显示红色并阻止保存/测试。动态数组实时展示和协议测试仍支持数量变化；当前新录制始终固定为本次首帧通道数，数量不符只跳过该帧并累计提示。历史变通道 CSV/WLR 文件仍可导入、合并导出，缺失通道记 NaN。

测试区的【样例格式】切换会转换当前输入的表示，保留相同字节；文本支持 UTF-8、\r、\n、\t、\\ 和 \xHH，HEX 仅接受十六进制，小写自动大写，非法输入/粘贴不插入。二进制协议生成样例或从 HEX 转成文本时，全部字节统一显示为 \xHH：例如 \x40、\x55，帧尾为 \x0D\x0A，不再混入 @、U 等可打印字符；文本协议仍保持可读文字和短转义。以前的混合字符/转义样例仍可解析，不改变字节内容。要逐字节查看可选择 HEX。【HEX 字节间空格】自动在每两位间插入显示空格，取消后连续展示；空格不计入数据，不需手工添加。半个 HEX 字节须补全后才能切换格式或解析。

点击【根据协议生成样例】，按右侧所选协议生成并验证一帧报文；当前项用草稿，其他项用已保存版本。自动处理前后缀、编码、字段类型/大小端、长度、帧头尾及校验，不改变协议、不发送。复杂固定条件或数值范围无法满足时提示并保留原输入，生成成功也不代表真实设备协议正确。【分包方式】模拟整块（最多 4096 字节）、逐字节或随机 1–31 字节的接收边界，正常结果应一致；统计显示次数及大小。【停止测试】仅处理过程中出现，可取消大样例并保留已完成结果；小样例通常瞬间完成。

解析失败时，下方红色诊断尽可能指出原始样例的字节偏移（从 0 开始）、帧内位置、预期与实际 HEX、出错通道/列号，并提示核对帧头尾、前后缀/结束符、分隔符、长度、校验、固定条件、编码或数值范围。无法确定的原因会标为“可能”，不会自动更改规则。样例结束还会检查未完成帧和缺失键值通道；这仅用于离线测试，实际设备接收仍正常等待半包。最多展示 100 条诊断，可选中复制。

【新增协议 → 二进制长度字段类型协议】自带动态数组样例；右侧【样例通道数】仅控制生成样例的数量，可用不同数量验证规则，不限制实际接收。首尾分隔可用于无需长度字段的 JustFloat 式报文，三种分隔方式、示例及限制见首尾分隔动态数组使用说明。

【新增协议 → 二进制首尾分隔类型协议】默认就是 JustFloat 式动态数组：无帧头、帧尾 0000807F、float32 小端、1–256 通道、无校验。通道数量按每帧实际数据区计算，通道表只覆盖名称/单位/备注/换算；未配置通道系数 1、偏移 0。支持仅帧尾、仅帧头或首尾配对，禁止首尾同时为空。仅帧头时，必须等下一个帧头才能输出上一帧，最后一帧暂存，生成样例自动附加下一帧头。首尾配对时新帧头可跳过缺少帧尾的坏帧。类型宽度不整除、通道数/帧长超限或校验错误整段拒绝，不裁剪成部分有效通道。

分隔模式没有字节转义：数据、保留/校验值以及跨字段组合可能与标记冲突，CRC 也不能消除分帧歧义。无帧头的初始半帧若恰好满足结构，无法判断完整性；从半个帧尾开始可能损失后续首帧。超长无帧头报文丢弃到下一完整帧尾后再同步，不把其后半段当作新帧。需要可靠处理任意二进制内容时，优先用长度字段＋校验。UDP 不跨报文保留半帧，单个数据报需提供完整边界；仅帧头时也需在同一数据报附加下一帧头。

串口、TCP 客户端/服务端、UDP 和 BLE 共用同一个当前数据协议，切换接口沿用当前选择；协议库和全局配置都只保存这一份选择。修改后自动应用到当前接口，重启后保留。Demo使用自身生成的数据，但不另行记忆数据协议。录制、发送或连接操作期间禁止切换协议；结构变化涉及绘图历史时仍需确认，不删除磁盘录制。

协议库每次保存时会备份上一次有效内容，用于文件损坏后的恢复，并非恢复出厂设置。正常管理区不展示恢复按钮，只有加载失败时才提供恢复入口；恢复前文件会另存保留。

方案可独立导入/导出 JSON；【设置】中的全局配置备份也包含协议库与选择。全局导入提供追加、按 ID 更新、替换和跳过，是否恢复协议选择可以单独决定。只有通过验证的数值帧参与录制，CSV/WLR 回放不重复执行自定义换算。可导入的样例位于 docs/protocol_examples。

BLE 蓝牙连接

选择【BLE 低功耗蓝牙】，点击【扫描…】并选择设备，然后点击【连接 BLE 设备】。发现服务后，选择“电脑接收（设备 → PC）”的 Notify/Indicate 特征和“电脑发送（PC → 设备）”的可写特征；可以只接收或只发送。收发方向以电脑为准，不直接照搬模块手册中的 TX/RX 名称。

首次连接展示【BLE 快速收发配置】，接收/发送选择和应用按钮位于主要区域。可以点击【使用候选通道】预选，或【仅接收候选通道】先观察通知；候选只依据属性和结构推荐，不保证是透传用途，不会发送探测命令。已知 Nordic 固件升级服务不参与推荐，手动选择时有警示。发送需要确认透传用途；写入模式自动适配特征，有响应写优先。缺少选择或模式冲突会直接提示原因。完整服务树、模板、写入模式、读取特征及分包控制在【高级配置】中，默认收起。

点击【应用并开始调试】，订阅成功后即可使用文本/Hex 收发和命令交互。成功配置会按设备保存，下次重新发现服务并核对结构、UUID 和属性；一致且发送参数无需风险确认时直接应用，无需重复弹窗，不会自动发送业务命令。旧配置、修改后的下次配置、重复 UUID、服务结构变化及需风险确认的高级参数仍须重新核对。需要配对时先在 Windows 设置中完成。

【收发配置…】可查看当前确认的配置，以及编辑供下次连接使用的 UUID 和写入模式。保存不会在线替换当前收发通道；【保存并重新连接…】会先确认，再重新发现服务并核对通道。录制、文件发送或连接操作进行中只允许查看。

展开【高级发送控制】，可设置分包大小（1–512 字节）和每包完成后的最小间隔（0–1000 ms），默认仍为 20 字节 / 10 ms。界面分别显示设置值与实际生效值：实际分包受 Windows 协商 MTU−3 和后端 512 字节上限限制；能力未知时最多 20 字节。Windows 上限不是模块缓冲容量，提高分包或降低间隔需要明确确认；导入模板不会自动授权提速。0 ms 仍逐包等待 GATT，不会并发发送。发送空闲时可【仅应用发送参数到当前连接】，确认成功后自动保存到该设备，不改变当前或已保存的下次连接 UUID。

能力增大不会自动提速；能力降低到不适合当前分包时，会停止待发数据并提供可复制提示，接收和录制继续运行。已提交的一包仍可能到达设备，不自动重发；重新应用合适参数后，由用户手动开始新发送。未经真实模块测试，不能保证更快参数不会导致外设丢包。

可以保存、导入和导出自定义 JSON 模板；模板不包含设备名称、蓝牙地址、文件路径和临时句柄。导入需要确认，同名模板覆盖也需确认。内置 Nordic UART 模板只是结构匹配候选，只有唯一 UUID 匹配才预选，仍需核对属性和透传用途；不会按设备名称猜测。HC-08 / E104-BT52 尚未实测，不附带猜测的专用 UUID 模板。

【连接诊断…】每秒更新可复制的状态、阶段耗时、通知与字节数、解析/录制计数及仅显示队列丢帧数。设备身份和错误路径默认隐藏，可主动勾选完整信息。未知适配器或 MTU 能力会标为未知；写入已接纳不等于已刷写到磁盘，Tx 也不等于设备业务确认。软件验证与硬件待测范围见 docs/ble-compatibility.md。

BLE 默认使用 Raw 文本/Hex 调试。外设发送数值时，可选择 FireWater、JustFloat（核对大小端）或匹配的自定义协议（包括多通道键值、CBF/IR/RED 模板），使用波形、滤波、频谱与信号分析，以及 CSV/WLR 录制和离线导入；录制时保留 Windows 通知的原始接收时间，跨通知的数值帧使用组帧完成那次通知的时间，同一通知中的多帧可能共用时间戳。CSV 的时间列为 UnixTime(s;FS=...)，以秒为单位保存主机接收时刻的 Unix 时间戳，FS 是采样率参考值；旧 HostReceiveTime 和 Hint 文件仍可导入。导入时可按现有“重建时间轴”机制查看批量发送的数据。

协议解析和录制在后台进行，录制先于绘图限流。接收积压或协议缓冲超过安全上限时会明确报错并停止连接，不能据此保证无线链路绝不丢包。Raw 模式和没有接收特征的连接不开放波形录制；录制期间不能切换协议。

BLE 文件发送在独立后台进程中打开和分段读取文件，使用有界缓冲和当前实际生效的分包/间隔；准备文件时显示等待状态，进度按 GATT 写入完成/提交计算，最后一包确认前不显示完成。发送期间禁止混入手动命令或循环命令，也不能修改发送参数。取消/掉线会清空尚未提交的数据，已提交的一包无法撤回，等待其结算后才可再次发送，也不会在重连后自动重发。源文件读取失败或超时会停止文件发送并提供可复制提示，不主动中断仍健康的 BLE 接收和录制；发送过程中请勿修改源文件。发送完成不等于外设业务层确认，非透传控制特征不要用自动分包发送。经典蓝牙虚拟 COM 口继续使用串口接口。

Windows BLE 后端由同目录的 WaveLinkBleHost.exe 提供。安装包和多文件便携包会包含它；Enigma 打包的便携程序也需附带这个辅助文件。开发时先运行 deploy/Build_BLE_Host.bat Debug，重新配置并构建 Qt 工程后会自动复制到主程序旁边。

波形查看与分析

- 在【数据通道】中勾选需要显示的通道；点击通道颜色块可调整曲线颜色。通道的勾选状态会保存。
- 主视图支持左键拖动平移、滚轮缩放时间轴。关闭【Y 轴自适应】后，可按住 Ctrl 滚轮调整 Y 轴。双击波形用于测量；【跳转至最新时刻】可回到实时数据。
- 右键点击通道可将其分离到独立视图；在独立视图右键菜单中可将通道合并回主视图。独立视图较多时，绘图区会提供纵向滚动。
- 【数字滤波】提供陷波、高通和低通；底部【频谱分析】可选择通道并设置 FFT 参数，【信号分析】用于查看所选通道的统计或信号特征。分析前应核对协议和采样率设置。
- 【波形历史上限】限制各绘图视图共同保留的历史数据，默认 64 MB。达到上限后，软件会清理最旧的显示数据；它不会限制完整录制文件。暂停绘图也不影响正在进行的磁盘录制。

数据录制、保存与导入

在左侧【数据存储】设置缓存路径和录制模式。建立连接后点击【开始录制】，文件将写入所选路径下的 WaveLink_Cache 文件夹。没有建立连接时无法开始录制。

自定义协议可选择录制保存的数值：通道表上方提供【录制保存数据类型】，默认为【原始数值（默认）】，也可选【换算后数值】。原始模式保存系数、偏移及超限 NaN 替代前的数值；换算模式保存 原始值 × 系数 + 换算偏移，并保留超限处理产生的 NaN。未配置通道按系数 1、偏移 0 保存原值。此选项按协议自动保存，随独立协议及全局配置导入导出；旧协议默认原始值。串口、TCP、UDP、BLE 的 CSV/WLR 均适用，两种数值类型都不包含界面数字滤波，与 CSV/WLR 格式选择相互独立。比如收到整数 2534、系数 0.01，实时波形显示 25.34，原始录制保存 2534，换算录制保存 25.34。原始数值指按字段类型及大小端解码的值，不是完整报文字节抓包。选项只影响之后开始的录制；“保存数据”合并或转换文件时保留已有值，导入不再套用当前协议缩放，旧文件不修改。

  功能       	说明                                      
  兼容模式（CSV）	文本格式，便于其他软件直接读取；高采样率、多通道时文件和转换开销可能较大。   
  高速模式（WLR）	WaveLink 二进制格式，适合高采样率、多通道或长时间录制；可重新导入，也可使用【保存数据】转换为 CSV。
  磁盘缓存上限   	检查 WaveLink_Cache 文件夹大小，同时作为录制磁盘的最低安全剩余空间；不是绘图历史上限。
  录前清空     	开始录制时清空当前显示的波形，不删除已有的磁盘录制文件。            
  导出当前波形   	保存当前仍在绘图历史中的显示结果，包含已应用的通道缩放、偏移及滤波，不能代替原始数据完整录制。

缓存文件夹超过设置上限时，开始录制前会询问：保留缓存并继续、清空缓存并继续，或打开文件夹自行处理。关闭提示框会取消本次录制；软件不会因缓存超限而直接删除文件。磁盘剩余空间不足时会提示并阻止录制。

【清空缓存】先展示确认窗口，说明缓存路径、文件数量、大小及影响；只有点击【确认清空】才删除本次列出的缓存文件，取消、Esc 或关闭窗口均不清理。删除释放的是磁盘空间，包括缓存中的录制、分卷及未恢复临时文件，无法撤销；请先另存重要录制。不清空当前波形或绘图内存，不删除缓存文件夹之外的另存文件，不递归删除子目录。录制中或其他实例正在使用时阻止清理；确认期间新增或发生变化的文件保留。

两种录制模式均支持单文件约 1 GB 自动分卷。录制完成后，【保存数据】可将完整录制及其分卷导出为 CSV；【导入数据】可加载 CSV 或 WLR 文件进行回放和分析。异常退出留下的临时录制文件会在下次启动时尝试恢复；若写入失败，录制会停止并显示错误。

CSV 录制、保存数据和导出当前波形统一使用带 BOM 编码标识的 UTF-8，以便表格软件识别中文通道名称。每个录制分卷有独立标识，合并后仅保留一个标识和一行表头；名称、数据及时间戳不变。旧的无 BOM UTF-8 CSV 仍可导入，重新使用【保存数据】导出时会补上标识，原缓存文件不修改。旧文件在表格软件中显示乱码时，可选择 UTF-8 编码导入；不要把已误读的乱码另存覆盖原文件。

WaveLink 录制时保存主机接收时间。批量接收的数据导入后会重建较均匀的显示时间轴，以避免波形阶梯化；这种重建属于估算，不能替代设备提供的精确采样时间戳。

命令与界面布局

【数据收发 → 发送文件】支持任意类型文件，包括图片、文档和压缩包，文件选择器默认显示所有文件。串口、TCP 和 BLE 均按文件原始字节分段发送，不受发送框 HEX/追加换行设置影响；.hex 文本文件也按原文发送，不自动解码。软件不会附加文件名、长度、校验或保存指令，接收端须自行约定传输协议及保存方式；UDP 和 Demo 不提供文件发送。进度条右侧仅显示预计剩余时间 时:分:秒，按最近实际写出/提交的字节速度估算；测速不足或长时间停滞时显示 --:--:--，完成、停止、失败或断开后显示 00:00:00。发送完成不等于接收端已校验或保存文件。

【数据收发 → 定时发送】按设定周期重复发送当前发送框内容，沿用 HEX 和发送追加换行设置，默认周期 1000 ms。第一个周期结束时首次发送，运行中修改周期会重新计时。周期自动保存，并随全局配置导入导出；开启状态不保存，重启或重连后不会自动发送。断开、切换接口、清空发送内容、开启 Break、取消待发送、开始文件发送或发送队列拒绝时自动停止。停止后不再提交新数据，已进入发送队列的字节仍可能发出，必要时使用“取消待发送”。周期是软件计时，不保证精确的设备到达间隔。

【保存接收】把点击时接收文本框中显示的内容保存为 TXT，默认名称为 WaveLink_Receive_yyyyMMdd_HHmmss_zzz.txt，可自行选择路径。文件使用带 BOM 的 UTF-8，保留当前的中文、HEX、时间戳和换行；选择文件期间新收到的内容不加入这次保存。空文本框会提示，不生成空文件。此功能只保存当前显示内容（受接收文本框历史清理限制），不替代持续录制或原始字节抓包。

接收区域第二行的【保存接收】、【复制接收】与【显示缓存】集中展示。【复制接收】可一键复制接收文本框的全部内容，保留当前的中文、HEX、时间戳和换行，不改变原内容或选区。文本框为空时会提示，并保留剪贴板原有内容。缓存说明可悬停【显示缓存】标签或下拉框查看，不额外占用工具栏空间。

接收区域的【显示缓存】默认保留最近 1000 行，可选 1000 / 2000 / 5000 行，并随软件配置保存、导入和导出。行数按换行分段计算，自动折行不额外计数；末尾空行也计一行。默认最多保留 5 万字符、每 100 ms 批量刷新；无换行的二进制/HEX 数据也受字符上限保护。达到任一上限时仅移除最旧内容，保留最新内容，不再整框清空；降低行数上限会立即裁掉多余历史，提高上限不会恢复已经移除的内容。此限制仅影响接收显示及【保存接收】/【复制接收】能取得的历史，不影响协议解析、状态监视、波形采集和 CSV/WLR 录制。完整数据请使用持续录制，而不是依赖接收框历史。

【设置 → 系统设置(O)】采用左侧分类、右侧详细设置，分类顺序为“界面设置 → 数据收发 → 绘图显示 → 软件更新”，默认打开界面设置；在设置菜单中按 O 可打开系统设置，“接收设置”快捷入口仍直接打开数据收发：“数据收发”可调整缓存行数、字符上限（1–25 万字符，仅整数，建议安装默认值 5 万，即 50,000 字符；1 万 = 10,000）和接收刷新间隔（下拉选项 50、100〔默认〕、150、200、250、300、500、1000 ms），接收区【接收设置】也可快捷打开；高速接收建议保持默认或降低缓存。“绘图显示”可调整波形目标刷新率（下拉选项 5、10、15、20、25、30〔默认〕、40、50、60 帧/秒），不改变设备采样率、Y 轴自适应或录制数据。【应用】或 Ctrl+S 保存且不关闭，【保存并关闭】保存后退出；恢复本页默认仅修改当前页草稿。设置自动记忆，并与全局配置导入/导出同步；旧配置未包含的新设置采用安全默认值，旧 10000 行选项迁移为 5000 行。

【帮助 → 版本信息】提供当前版本、检查更新、更新说明和安装包下载；系统设置的【软件更新】可开关启动后自动检查（默认开启，每天最多一次），并纳入全局配置导入导出。未配置发布地址/公钥时明确提示，保留手动下载；不会连接示例服务器。下载与采集录制互不打断，安装需要先结束录制、停止发送并断开设备，确认后备份配置并退出；安装版覆盖升级，不先卸载、不清理录制缓存。便携/开发目录不自动覆盖安装。更新验证签名、大小与 SHA-256；失败不安装。发布工具与接入说明见 在线更新发布指南。

系统设置中的【界面设置】可设置【恢复默认布局】时下方数据收发、频谱分析、信号分析区域的高度占比，默认 30%（上方约 70%），范围 20%–50%。它按当前窗口工作区计算，不包含菜单、工具栏和状态栏，不再采用屏幕高度的 25% 且限制为 220–320 像素的旧规则；实际高度仍受控件最小尺寸限制。保存设置不立即打乱当前布局，点击【恢复默认布局】或首次没有已保存布局时采用该比例；手动调整的布局仍正常记忆，数据收发模式内部的接收/发送分割比例不受影响。比例参数随全局配置导入导出。

【工具 → 命令交互面板】可保存常用命令。左键发送/切换保持原有行为；短按右键打开菜单，长按右键约 0.7 秒直接编辑，也可从菜单选择【编辑命令】。打开菜单或编辑本身不会发送。菜单保留新增、复制、调整顺序和删除，前部按命令类型提供发送功能：

- 普通命令：发送一次。
- 定时命令：发送一次、开始定时发送、停止定时发送；发送一次不改变当前定时状态。开始定时时先立即发送一次，再按周期循环，区别于数据收发区一个周期后首次发送的定时发送；停止后已排队字节仍可能发出。
- 开关命令：切换并发送，或指定发送状态 0/1；可重发当前状态，只有发送入口接纳后才更新显示，仍不代表设备确认执行。
- 滑条命令：发送当前值、恢复默认值并发送；列表模式还可选择列表项，发送该编号对应的实际内容。显式菜单发送允许重发同一数值，不受滑动过程的重复值抑制影响。

发送沿用当前 HEX、前后缀及追加配置，仍受连接、Break、队列等现有条件约束。面板内有独立的使用说明。

文本命令以 UTF-8 发送，接收框的 UTF-8/GBK 选项不改变发送编码；键入 \r\n 不会自动转义，实际换行请用追加选项，或在命令编辑框中用 Ctrl+Enter / Alt+Enter 插入 LF。常规滑条即使勾选 HEX，变化数值仍按十进制文本发送，不自动编码为二进制整数/浮点数；例如 HEX 前缀 AA、数值 20（小数位 0）发送 AA 32 30。需要离散二进制参数时可用列表模式填写实际字节。

独立命令面板 JSON 备份面板、命令与布局，不包含设备连接参数、自定义协议库和软件全局偏好；整体迁移请使用“设置”中的导出配置 / 导入配置。运行中的定时发送、开关当前状态和滑条当前值不会作为自动发送任务恢复。

左侧命令面板列表的项目和空白处均可右键打开菜单，支持新增面板、导入面板和导出所有面板。右键某个项目时，重命名、复制、删除、查看说明、导出当前面板和上移/下移均针对该项目；空白处这些操作置灰，不改变之前选中的面板。没有面板时，“导出所有面板”不可用。

按钮、滑条和开关命令均可填写“说明”（原“备注”），不参与发送。鼠标悬停在命令上只展示说明内容，保留多行和特殊字符；没有填写时显示“暂无说明”。提示框适配浅白、暗黑主题。旧配置中的命令备注会自动作为说明读取，独立面板及全局配置导入导出仍保留该内容。面板名称和面板说明统一在右上角【面板设置】中修改，旧面板备注仍兼容读取。左下角【导出所有】导出全部面板；右键列表可导出单个面板。

悬停说明会根据鼠标所在屏幕的可用空间自动换行，连续长串字符也会折行。能容纳时完整显示，过长时仅预览前部并提示右键编辑查看完整说明，避免提示框超出屏幕；原始说明始终完整保存，编辑窗口内可滚动查看全部内容。

旧版命令配置中缺少可补充的开关字段时，软件会先完整备份原文件再自动兼容。若开关的两段命令内容缺失，会保留该命令并标记“待补全 · 禁止发送”，其他面板仍可使用；右键编辑并填写两个状态的命令后保存即可恢复。配置无法读取或被其他实例修改时，窗口上方提供“一键修复”，优先修复当前文件，无法修复时尝试最近有效备份；原文件另存为 cmd_panels.json.before-repair-日期-标识.json，正常保存还会维护 cmd_panels.json.bak。无法恢复时保留原文件，不用空配置覆盖。导入独立面板和全局配置使用相同的兼容规则。缺失且无备份的命令正文需要重新填写。

命令类型支持按钮、滑条和开关命令。开关与普通按钮尺寸相同，采用滑块式外观，只有状态 0/1；每个状态分别设置命令、状态名称和颜色，默认状态名称为关闭/开启，也可用于模式 A/B。点击发送另一状态的命令，只有成功提交到当前接口发送队列后才切换显示；未连接、Break 占用或队列拒绝时状态不变。显示仅表示软件请求，不代表设备已确认执行。HEX 与追加方式共用，HEX 只限制命令及自定义追加，状态名称和说明不发送、可任意输入。两个状态均可选透明颜色并适配主题；命令输入自动增高，超过 10 行内部滚动。开关不定时轮换；启动、重连、导入、切换面板或主题不会自动发送。保存默认状态、不保存运行状态，重启或重新载入按默认状态展示；全部配置随面板及软件整体配置导入导出。

命令/前缀及附加命令输入框随内容自动增高，最多显示 10 行（含自动换行）；超过 10 行后才显示内部滚动条，删减内容后自动收回。编辑窗口高度不足时可通过表单整体滚动条查看其他设置，底部保存/取消按钮保持可用。

命令、附加命令及自定义追加输入框在 HEX 模式下，支持粘贴带空格、换行或制表符的多行字节，也支持 5A5A5A 这样的连续内容，自动显示为大写并按字节加空格；空白不发送。支持快捷键及右键粘贴、复制、剪切和撤销；含其他字符的粘贴不会改变原内容，不接受 0x 前缀、地址或注释。保存时检查每个字节必须完整两位。

左侧面板列表右键可【复制面板】，保留说明、命令和布局，副本放在原面板下一行，名称自动添加 _1、_2 等后缀。副本不会自动启动定时发送，原面板的运行状态不受影响。

顶部【数据收发模式】会暂时只显示参数设置和数据收发面板，再次点击恢复切换前的布局。面板可折叠、拖动调整大小；布局混乱时点击【恢复默认布局】。软件还支持深色/浅色主题，以及通过【设置】菜单导出、导入配置。

状态监视

从主窗口【设备交互 → 状态监视面板】或【工具 → 状态监视面板】打开。首次使用先新增面板，再添加监视项；同一面板可同时监视通道数值与接收文本。顶部面板总开关与面板设置中的启停同步；重新启用会保留各监视项原有的启停设置，不影响设备连接和录制。

- 通道数值：默认使用原始值，可改为换算后数值，与录制保存方式独立。支持数值映射、位段解析和阈值区间；实时状态可设置生效延迟（防抖）、回差与超时。按指定协议绑定可避免切换协议后误解释同一通道；也可明确选择跟随通道编号。
- 接收文本：填写设备实际反馈，支持完整匹配和前缀匹配，不限于 ACK。配置编码、结束符、首尾空白和大小写处理；UDP 可使用整报文。同一面板的多个监视项可复用文本来源。Demo 没有设备文本反馈；Raw 模式仍可监视真实接收文本。
- 验证与展示：规则编辑窗口可生成样例、手动解析测试、模拟分块输入，不发送数据，也不改动实时状态。卡片显示状态及等待、未知、异常、超时、断线等信息；规则颜色列直接显示色块，不显示编码；棋盘格表示默认/透明，双击可选择颜色，颜色窗口为中文；点击“拾取屏幕颜色”下方的“使用透明颜色”可清除自定义颜色，恢复主题默认显示，保存监视项后生效，文字不会隐藏。有效状态还以蓝色“提示”、橙色“警告”、红色“错误”标识严重程度，“无”不显示标识，不自动发送命令或弹窗；左键启停此监视项，短按右键打开菜单，右键长按编辑，可拖动排序，不影响设备连接。编辑中 Ctrl+S 仅保存，左侧“保存监视项”保存并关闭，下方“关闭编辑”不保存未提交的修改；规则增删、排序支持 Ctrl+Z（文本输入时优先撤销输入）。
- 绑定与时间：“锁定协议及结构”会校验协议标识和结构，避免切换协议后误读；【选择协议】按“系统协议 / 自定义协议”分组，JustFloat 的大小端分别列出，Raw 不提供数值通道、不可选。协议绑定统一在“面板设置”中配置，新面板默认锁定当前有效数值协议，监视项继承面板绑定而不重复选择；无数值协议时默认跟随。旧面板绑定一致时自动迁移，混合绑定保留原行为并提示统一，不直接覆盖；选择协议后来源通道显示对应协议的名称，通道序号不变。锁定的协议名称单独显示，支持复制，协议缺失、当前使用其他协议或结构已变更时会提示，不会静默改绑。旧结构显示“保留结构”，明确选择列表中的最新协议后才更新绑定。选择协议及“绑定主界面当前协议”统一作用于该面板的通道数值监视，保留通道编号，不切换采集协议；文本监视保持独立。编辑项显示继承的协议及匹配状态，已知通道范围外会提示检查。“跟随当前协议的通道序号”不校验协议，由用户保证通道含义一致，两种方式均按序号而非名称查找。协议及来源通道下拉最多显示 10 项。保持时间为条件持续满足后的生效延迟，0 即立即生效；有效期为无新有效数据的超时期限，新建项默认“不自动过期”（0 ms），已有项保留已保存期限；设备断开仍立即失效。支持时间预设和自定义毫秒数。
- 记录与保存：关闭监视窗口仍继续监视，停用面板或监视项才停止对应判断。最近状态记录在内存中最多保留 2000 条，默认记录变化，文本可记录每次匹配；筛选只影响显示，导出包含全部保留记录，清空记录不清零触发/屏蔽次数或清除卡片提示。记录不跨重启保留；来源诊断有数量上限，不是长期日志。面板自动保存，支持独立 JSON 导入/导出、选择及窗口位置记忆，异常配置保留原文件，可恢复有效备份。

实时状态与事件提示：在“解析来源”下方选择监视模式。已有配置默认仍为实时状态，按最新数据更新；事件提示适合单帧标记、瞬时故障或一次性反馈。后台在绘图合并之前逐帧判断，新建提示默认保持至手动清除或下一事件（0 ms），也可选择定时清除；新事件立即替换当前提示，不排队弹窗，全部触发进入有限历史记录。事件模式不使用生效延迟和恢复回差，避免过滤掉瞬时输入。卡片显示触发次数与屏蔽条数，右键“清除事件提示”仅清除本项显示，不清零次数、不删除历史、不影响设备。次数在断线重连、改变影响解析的配置或重启后重新累计；仅修改名称、说明、颜色等展示信息不因此重置当前监视状态。

事件屏蔽条件最多 64 条，任一启用条件命中即静默：数值来源支持“固定数值”和“数值区间”，文本来源还支持“固定文本”。新建数值监视切到事件模式时默认屏蔽 0，可删除、修改或取消勾选；区间包含上下限。数值条件作用于所选原始/换算值、位段提取之前；固定数值精确比较，浮点数建议使用区间。文本条件作用于完整分帧、解码和空白处理后的正文，大小写遵循文本来源设置；数值类条件要求整条正文可解析为有限十进制数（可用科学计数法）。不使用表达式或正则脚本。屏蔽及未匹配内容不覆盖、不延长已触发的提示；屏蔽不会改动接收文本、协议解析、绘图、录制或其他监视项，NaN/Inf、缺少通道和断线不能被屏蔽。

重复触发可选“进入匹配状态时触发”或“每次匹配均触发”。前者适合脉冲标志：连续命中同一数值、位段、区间或文本规则只触发一次，遇到屏蔽/未匹配内容后重新等待进入；提示过期或手动清除后，持续相同输入不会立即重新触发。后者适合每条反馈都代表独立事件，连续匹配会持续计数并重置提示时间。事件模式中的“数据静默超时”与提示保持时间独立：有效数值帧或合法完整文本消息表示来源仍活跃（包括屏蔽/未匹配内容），但不会因此延长提示；数据超时、断线和异常优先显示，文本队列遗漏反馈仍会警告。

例如 500 Hz 通道通常为 0、偶尔单帧为 10 或 20：选择“通道数值 → 事件提示”，锁定对应协议及通道，使用原始数值，数值映射添加 10 → 状态A、20 → 状态B，保留固定数值 0 的屏蔽条件，重复触发选“进入匹配状态时触发”，提示保持时间设为 2000 ms。后续 0 不会盖掉事件，下一次 10/20 会重新触发；同一卡片显示最新事件，如需同时保留两种提示可分别创建监视项。解析测试使用同一规则，显示触发次数与屏蔽数，自动生成样例会跳过能识别的已屏蔽值；无法生成时可手动输入。模式及屏蔽条件随本机保存、面板导入导出和全局配置一并保存，旧格式配置兼容读取。

软件【设置】菜单的全局配置会包含全部状态面板、规则、共享文本来源及窗口偏好。导入可对状态面板单独选择覆盖、追加或跳过；旧配置没有状态块时保留当前内容。追加会生成新的面板/监视项/文本来源 ID 并避免面板重名；自定义协议按追加导入时，导入监视项的绑定会同步映射，缺失或已过期的结构绑定不会自动改为跟随通道。导入失败会恢复原有设置与配置文件，中断的事务在下次启动时恢复。

状态监视不自动发送或重试命令、不更改命令开关状态，不把反馈混入数值录制。任意二进制与文本混传必须有可靠的外层边界，不能仅凭关键词确认设备反馈。面板【导出所有】保存全部状态面板，右键列表仍可导出当前面板；独立导入不携带自定义协议库或窗口位置；追加时重新分配 ID 并自动避免面板重名，覆盖时替换全部状态面板。独立导出禁止覆盖内部配置、备份和窗口偏好文件。跨机器建议使用全局配置一并迁移。

常见问题

- 连接后没有波形：先检查【数据收发】是否有数据，再核对协议、通道勾选和采样率。Raw 主要用于文本/Hex 调试，不会把任意文本自动变成有效数值波形。
- 录制文件比当前波形更长：这是正常现象。绘图历史会按内存上限丢弃旧数据，完整录制仍持续写入磁盘。
- 无法开始录制：确认连接已建立、缓存路径可写，并查看是否出现缓存超限或磁盘空间提示。
- 需要帮助或排查异常：打开主窗口右上角的帮助中心，查看使用说明、协议文档和程序调试日志。
